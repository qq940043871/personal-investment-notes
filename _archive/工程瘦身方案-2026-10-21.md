## 三、执行清单（按优先级）

### P0 · 零风险，可立刻做（约 23 MB）

- ⚠️ 本机删除走回收站：用 `C:\Users\qq940\anaconda3\python.exe` + `send2trash`，**路径必须反斜杠**（正斜杠会报 `OSError(22)` 且真删不掉），并用 `os.path.exists()` 复核成败。

### P1 · 需要你拍板（56 MB + 决策）

**B. 清 git 历史里的 `slides/`（56 MB / 171 文件）**

```bash
# 1) 先整仓备份（必须）
cp -r "D:/ai_person/personal-investment-notes" "D:/bak_notes_$(date +%Y%m%d)"

# 2) 清理（需先 pip install git-filter-repo）
git filter-repo --invert-paths --path slides/ --force

# 3) 强制推 —— 注意：本项目 git push 被代理阻断，走 API 脚本
python .workbuddy/push_github.py
```

- **收益**：`.git` 72 MB → 约 16 MB，是**全案最大单项**。
- **风险（必须知情）**：
  1. **改写历史** → 所有 commit SHA 变化，本地需 `update-ref` 对齐（项目已有该流程，见 `push_github.py`）。
  2. 强制推需用 API 的 `PATCH /git/refs/heads/main` 带 `force=true`；现有 `push_github.py` 是否支持需先确认。
  3. 若他人 clone 过该远程，其本地会冲突——**个人笔记仓库一般无此问题**，但仍请先确认。
- **折中方案**：若不想改写历史，可只做 `git gc --aggressive --prune=now`（不清历史，仅压缩，收益有限）。

**D. 八股 13 组同名 `.html`（932 KB）—— 二选一**
- **砍**：md 为唯一权威源件，需要网页版时用 `_build/` 现有转换脚本现转。
- **保**：保留离线阅读能力，但**停止手工同步**（总览 §五已把此项列为"待确认"，本次一并裁决）。
- 建议：**保**。理由——手机/离线场景确实需要，且体积仅 0.9 MB，性价比高于清理成本。

**E. `02-面试背诵集合.html`（824 KB）**
- 它是**快照件**（13 组 md 汇总内嵌），题库更新后会滞后——这是**口径风险**，不是体积问题。
- 处置：在文件顶部加"快照生成时间 + 源件清单"声明；或在 `_build/` 下补一个生成脚本，明确其为**可重建产物**。
