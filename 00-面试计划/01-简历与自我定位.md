# 01 · 自我定位

> 背到脱口而出，任何岗位都要说。

## 一句话定位

13 年 Java 后端，在郑大信息负责 **B2B 大宗商品交易平台的 Java 侧**：**在一个"C 单线程撮合 + Java 微服务中台"的异构系统里，管住两边对话的那一层**——不写 C，但通过自研 DS 数据交换中心管住协议转换、连接管理、可靠性和容量，让黑盒可控。

## 三个差异化标签

| # | 标签 | 一句话 |
|:--:|---|---|
| ① | **驾驭 C+Java 异构架构（市场稀缺）** | 负责 C 单线程内存撮合 + Java 微服务中台的异构四层系统；不写 C，但用自研 DS（防腐层）管住 TCP 二进制 ↔ Hessian 的协议转换、连接、可靠性、容量 |
| ② | **技术与业务深度交叉（B2B 最稀缺）** | 能把"支持分批付款"五个字拆成 14 个子需求、识别 3 个风险点；评审时反问"合同条款的违约触发条件对应系统哪个状态节点" |
| ③ | **从执行者到领导者（用机制替代亲力亲为）** | On-call 主副双岗、技术债台账、接口契约治理、20% 带宽原则；被动响应 45%→15%，团队独立处理 80% |

**加分句**："我还在一线——代码评审、方案设计、疑难兜底都有我。所以我出的方案不飘：能不能落地、坑在哪、工作量多少，我能直接判断。"
（翻译给面试官：**你不是只会开会的 leader**。）
