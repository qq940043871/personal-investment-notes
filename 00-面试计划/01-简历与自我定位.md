## 1. 自我介绍（三版，按岗位挑一版背）

### 1.1 通用版（60 秒，任何岗位开场）

> 面试官好，我是 XXX，13 年 Java 后端经验，现在在郑大信息负责 **B2B 大宗商品交易平台的 Java 侧**。
> 我做的事情可以概括成一句话：**在一个"C 单线程撮合 + Java 微服务中台"的异构系统里，管住两边对话的那一层**——我不写 C，但通过自研的 DS 数据交换中心管住协议转换、连接管理、可靠性和容量，让黑盒可控。
> 业务上我熟大宗全链路：挂牌询价、合同签约、仓单流转、物流跟踪、结算开票，一句业务诉求我能拆成子需求和风险点。
> 团队上我从"凌晨被叫醒的人"转成了"建机制的人"：On-call 主副双岗、技术债台账、接口契约治理，被动响应从 45% 降到 15% 以下。
> 我到现在还在一线做方案和疑难兜底，所以我的方案不飘——落地成本和坑在哪，我能直接判断。

### 1.2 架构师版（90 秒，突出技术深度）

> 同上开场三句，然后加一段：**"我最有代表性的三件事是——网关十道关、扩容打穿 DB 的根治闭环、C+Java 异构一致性。"**
> 网关：按"拒绝要早、要便宜"排序，契约注册表一处定义四处生效。
> 高并发：网关扩到 5 实例后把后端 DB 打死，我用利特尔法则反推限流值，四层治理把"瓶颈后移"变成"容量可算"。
> 一致性：跨系统只保证"最终被确认"，本地消息表 + 批次号原子认领 + 阶梯重试；C 核心用镜像落盘 + 异步回写 + 死信兜底。
> 这三件事的共同点是：**都从"一个具体故障/约束"出发，落到可复用的规范，而不是一次性的救火。**

### 1.3 技术经理版（90 秒，突出管理）

> 同上开场两句，然后：**"我这三年的主线是从执行者转成操盘手。"**
> 被动响应 45% → 15%；团队能独立处理 80% 现场问题；技术债从隐性→显性→可控（台账 + 每月固定偿还额度）；
> 接口契约治理："管连线不管黑盒"——我定契约与爆炸半径，不介入对方实现。
> 带人上我的原则是**用机制替代亲力亲为**：值班表、复盘五列、灰度与回滚红线。
> 但我不脱离一线——方案评审和疑难兜底都还在我这儿，所以我定的排期团队认。

> **雷区**：不要说"我现在做得比较多的就是现场生产问题排查"。同样的事实，这句会把自己讲成救火队员。改成：**"我对全链路最熟，所以复杂问题我能快速定位根因；同时我把典型问题沉淀成手册和告警规则，团队能接住 80%。"**

## 2. 三个差异化标签（背到脱口而出，任何岗位都要说）

| 标签 | 一句话 | 支撑素材 |
|---|---|---|
| **① 驾驭 C+Java 异构架构（市场稀缺）** | 负责 C 单线程内存撮合 + Java 微服务中台的异构四层系统；不写 C，但用自研 DS（防腐层）管住 TCP 二进制 ↔ Hessian 的协议转换、连接、可靠性、容量 | 成长手册 第一部分 §1.3、第四部分 §三 |
| **② 技术与业务深度交叉（B2B 最稀缺）** | 能把"支持分批付款"五个字拆成 14 个子需求、识别 3 个风险点；评审时反问"合同条款的违约触发条件对应系统哪个状态节点" | 成长手册 第二部分、第一部分 §九 |
| **③ 从执行者到领导者（用机制替代亲力亲为）** | On-call 主副双岗、技术债台账、接口契约治理、20% 带宽原则；被动响应 45%→15%，团队独立处理 80% | 成长手册 第三部分、第四部分 §二（资产盘点） |

**加分句**："我还在一线——代码评审、方案设计、疑难兜底都有我。所以我出的方案不飘：能不能落地、坑在哪、工作量多少，我能直接判断。"
（翻译给面试官：**你不是只会开会的 leader**。）

## 3. 高频开场追问（前五分钟决定成败）

| 追问 | 答 |
|---|---|
| 先自我介绍一下 | 用 §1 对应版本，**控制在 60–90 秒**，末尾留一个钩子（"最有代表性的是网关和一致性两块，看您想先听哪块"） |
| 你现在日常工作都在做什么 | §1 的"守城"版：全链路最熟 + 沉淀成手册与告警 + 只介入疑难 |
| 为什么想换工作 | 讲**增长**不讲**逃离**：平台已稳定、想做大宗之外的复杂系统 / 更完整的技术决策权 |
| 13 年为什么还做一线 | "一线是我的信息源。不在一线，方案一定是拍脑袋。" |
| 你最大的短板 | 给一个**真短板 + 已采取的动作**：算法与手写代码（`17` 缺口 1）、C 内部实现（用契约与爆炸半径兜） |
| 期望薪资 | 区间 + "看岗位职责与团队规模"；不先报死数 |
| 你还有什么问题 | 问**团队现在的技术债与 On-call 机制**、**这个岗位半年内最想解决的一件事**（比问薪资、加班更显层级） |

## 4. 简历里"必须能接住"的三类炸弹

1. **写"精通"的那几项** → 全部引导到"网关 + 高并发"，其余降级（`05`）。
2. **AI 段** → 主动收窄，绝不自曝矛盾，也绝不硬撑"技术负责人"（`03` §10）。
3. **"零资金差错 / 200ms / 对账 9 人天→2 小时"** → 每个数字都要能说清"**统计位置 + 分母**"，说不清就改说"我们关注的是零差错，靠对账兜底"（`02` §8 自查缺口）。
