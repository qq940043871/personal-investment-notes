## 📖 概述

本人**未落地 CDN 加速**。本章介绍的静态资源优化、动静分离与对象存储（MinIO）为本人已落地手段。

## 🔧 一、静态资源优化

### 1.1 资源分类

| 类型 | 缓存策略 | 示例 |
|------|----------|------|
| **静态资源** | 永久缓存+版本化 | JS/CSS/图片 |
| **动态资源** | 不缓存或短缓存 | HTML/JSON |
| **用户资源** | 私有缓存 | 用户头像 |

### 1.2 缓存策略

```nginx
# Nginx配置示例
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
    expires 1y;                          # 缓存1年
    add_header Cache-Control "public, immutable";
    access_log off;                       # 关闭日志
}

location ~* \.(html|json|xml)$ {
    expires -1;
    add_header Cache-Control "no-cache, no-store";
}
```

## ⚡ 二、动静分离

### 2.1 分离架构

```
┌─────────────────────────────────────────────────────────┐
│                      用户请求                               │
└─────────────────────────────────────────────────────────┘
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
    ┌───────────┐  ┌───────────┐  ┌───────────┐
    │  静态请求  │  │  动态请求  │  │  接口请求  │
    │  (CDN)    │  │  (Nginx)   │  │  (Gateway) │
    └─────┬─────┘  └─────┬─────┘  └─────┬─────┘
          │               │               │
          ▼               ▼               ▼
    ┌───────────┐  ┌───────────┐  ┌───────────┐
    │ OSS/MinIO  │  │   Tomcat  │  │  微服务   │
    │  存储      │  │  应用      │  │  集群     │
    └───────────┘  └───────────┘  └───────────┘
```

> 注：本人 B2B 项目使用 **MinIO** 作为对象存储（因私有化部署需求），OSS 为通用替代方案。

### 2.2 文件服务选型

| 方案 | 适用规模 | 特点 |
|------|----------|------|
| **NFS** | < 100TB | 简单、低成本 |
| **FastDFS** | 100TB-1PB | 高并发、分组 |
| **OSS/MinIO** | PB级+ | 云原生、托管（本人采用 MinIO 私有化部署） |
