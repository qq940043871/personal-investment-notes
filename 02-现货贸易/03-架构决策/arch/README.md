## 🔥 核心问题速查

### Q: 多货是怎么实现的？
**A**: 详见 [库存超卖与多货](./10-库存超卖与多货.md)

核心思路（本人 B2B 大宗平台库存链路的落地做法）：
1. **库存预扣**：下单时预占库存，支付后真正扣减
2. **锁机制**：Redis 分布式锁 + 数据库乐观锁双重保障
3. **消息队列**：异步解耦，防止并发冲击
4. **对账机制**：日终对账，异常订单自动补偿

### Q: 怎么支持高并发？
**A**: 详见 [高并发处理策略](./04-高并发处理策略.md)

核心手段（通用方案 + B2B 可迁移）：
1. **流量控制**：限流、熔断、降级
2. **缓存前置**：多级缓存、热点数据预加载
3. **异步化**：MQ 解耦、非核心链路异步处理（B2B 用 Kafka + outbox + 幂等）
