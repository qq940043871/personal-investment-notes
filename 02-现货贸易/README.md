## 🧭 读法建议

1. **先业务后技术**：`01-业务与价值`（为什么做 / 客户是谁 / 痛点在哪）→ `02-客户与案例`（怎么讲给客户听）→ `03-架构决策`（技术上怎么落地）。
2. **面试叙事主线**仍以 [`../00-面试计划/02-项目叙事-B2B.md`](../00-面试计划/02-项目叙事-B2B.md) 为准，本目录是它的**依据库**。
3. **排查与容量**：`04-生产问题排查/` 出事故复盘口径，`03-架构决策/midservice/` 出容量与压测口径，`03-架构决策/dataShare/` 出异构桥接与缺陷口径。
4. **补通用知识**：卡在"行业标准做法是什么"时进 [`arch/`](./03-架构决策/arch/README.md)，那里只讲通用方案并标锚点。
