# 面试速记卡（当天 10 分钟通读）

> 面试当天早上 10 分钟通读一遍：六维（产品 / 客户 / 痛点 / 价值 / 定位 / 贡献）＋ 开场锚点 ＋ 必背数字 ＋ 管理金句。**本手册是面试当天唯一的速查件。**（完整展开版见 [01-面试话术与背诵手册.md](01-面试话术与背诵手册.md)）

### 一、产品概述

**我们是什么**：B2B 大宗商品现货在线交易与供应链服务平台——让钢铁、煤炭、化工等大宗贸易全链路数字化的产业互联网平台。

**核心功能：三位一体**

```
电子交易（基础） ←→ 现代物流（保障） ←→ 供应链金融（增值）
      │                     │                    │
  撮合买卖双方          货权清晰可控        交易数据变信用资产
```

**多类交易模式**：挂牌 / 竞价 / 询价 / 招标 / 基差点价等多种模式（注意："7 种"是交收模式口径，与交易模式别混用）

**三个核心特点**

| 特点 | 一句话 |
|------|--------|
| 全链路线上化 | 询价→合同→支付→仓储→物流→质检→结算→开票，全程在线 |
| 交收场景化 | 先合同后款、先款后合同，用场景化收敛参数，避免参数爆炸 |
| 金融级可靠性 | 三年零资金差错、外部接口平均可用率 99.95%、电子仓单零重复质押 |

**技术架构一句话**：C 语言单线程内存撮合内核（纳秒级、无 GC）+ Java 微服务业务层 + Vue 三端，通过自研 DS 数据交换中心做异构桥接。**C 负责快，Java 负责稳，DS 负责翻译，网关负责守门。**

### 二、目标客户

**行业**：钢铁、煤炭、化工、农产品、有色金属等大宗商品领域。

**客户规模分层**

| 类型 | 画像 | 核心诉求 |
|------|------|---------|
| 大型核心企业（钢厂/上游矿企） | 年交易额数十亿，有稳定下游渠道 | 扩大销售半径、供应链金融、API 对接 ERP |
| 中型贸易商 | 年交易额数千万至数亿，10-50 人团队 | 稳定货源、拓展新客户、资金周转 |
| 小型贸易商/加工厂 | 年交易额百万级，现金流紧张 | 便宜货源、集采拼单、小额融资 |

**关键角色**

| 角色 | 典型痛 | 平台给他们什么 |
|------|--------|--------------|
| 采购经理 | 每天打 20 个电话比价找货 | 一键比价 + 库存实时 + 供应商信用档案 |
| 财务总监 | 月底对账 3 人 3 天还对不齐 | 自动对账 + 三流匹配 + 零差异 |
| 风控总监 | 怕一货多押、怕坏账 | 电子仓单 + 区块链存证 + 银行实时校验 |

### 三、解决的问题（四个死结）

> 详细表见 [§六.②](01-面试话术与背诵手册.md#-解决问题客户买单的四个死结)，这里只留背诵版。

1. **不敢买（信任）**：靠熟人关系做生意 → 平台担保 + 资金存管 + 履约信用档案。**本质：把对人的信任变成对系统的信任。**
2. **找不准（信息）**：打五个电话比价、说有货其实没货 → 实时行情 + 一键比价 + 库存与 WMS 实时校验。
3. **跑断腿（效率）**：合同邮寄、跑柜台、Excel 对账 → 电子签章 + 银企直连 + 物流轨迹 + 自动勾稽。**一笔交易 5~7 天 → 1.5 天。**
4. **缺钱（资金）**：看到低价货没钱吃 → 预付融资 / 仓单质押（约货值 70%）/ 应收融资（约 80% 变现）。**让钱不够的买方也能成交，直接提高成交率。**

**为什么银行做不了、我们能做**：平台有真实交易数据，银行才敢放款。没数据的人做金融是在猜，我们是在算。

### 四、产品价值

**三层价值结构（从下往上讲）**

```
第三层：增长价值（壁垒）  →  月交易量翻倍 / 供应链金融开展 / 数据飞轮
第二层：风险价值（B2B独有）→  零资金差错 / 零重复质押 / 合同自动校验
第一层：效率价值（最易量化）→  5~7天→1.5天 / 对账9人天→2小时 / 签约1周→1天
```

**一句话价值主张**：把大宗贸易从"靠人脉、靠电话、靠运气"的生意，变成"靠数据、靠系统、靠信用"的生意。

**核心数字**：交易周期 5~7 天→1.5 天 ｜ 对账 9 人天（3 人×3 天）→2 小时 ｜ 新客户上线 2 个月→1 周 ｜ 资金差错 0 ｜ 重复质押事故 0 ｜ 外部接口平均可用率 99.95% ｜ 客户培训 半天→30 分钟。

**竞争壁垒（五个不可复制）**

1. **数据飞轮**：交易越多→数据越多→风控越准→金融越便宜→客户更多
2. **场景化引擎**：100 个客户喂出来的抽象能力，新进入者至少 2 年
3. **外部集成深度**：已对接 5 家银行、10 个仓库 WMS 等外部系统（外部接口 9+），追赶成本极高
4. **行业复合人才**：既懂技术又懂大宗，培养周期 2-3 年
5. **信任资产**：时间 × 零事故 = 不可速成的护城河

### 五、个人定位

**我的角色**：B2B 现货贸易平台技术经理，带 20 人研发团队（3C / 6Java / 5Vue / 5 测试），向总经理汇报；直接负责**业务层**与**数据交换层**的边界治理，业务上负责**合同复杂交收 + 履约保证 + 规则配置 + 生态对接**。

**三维定位公式**

```
技术经理 = 业务翻译官 + 技术操盘手 + 流程守护者
```

| 维度 | 我做什么 |
|------|---------|
| 业务翻译官 | 把"支持分批付款"五个字拆成 14 个子需求、识别 3 个风险点；能反问"这个违约触发条件，系统哪个状态节点对应？" |
| 技术操盘手 | 四层边界怎么切、异构怎么治、技术债怎么还；不写 C 代码，但通过 DS 管住异构通信全链路 |
| 流程守护者 | On-call 轮值、技术债台账、接口契约治理，让团队从被动救火转向主动建设 |

**管理理念**：深度区直接掌控（合同交收、履约保证、数据交换、规则配置、生态对接），治理区契约管理（C 撮合内核、财务清结算、物流执行）。**我管"连线"不管"黑盒内部"，守住接口、SLA、爆炸半径。**

### 六、个人贡献（五个成果，面试挑 2-3 个讲）

#### 成果一：DS 数据交换层 — 驾驭 C+Java 异构架构

| 问题 | 方案 | 结果 |
|------|------|------|
| C 撮合内核是黑盒，只暴露 TCP 自定义二进制协议；上层 12+ Java 微服务无法直接通信 | 数据交换层做防腐层（Anti-Corruption Layer）：Java NIO 收二进制帧 → 协议解析/版本路由 → 上层 Hessian 暴露标准 DTO | 异构复杂度收敛在一层，C 与 Java 各自独立演进、互不阻塞 |

> **金句**："我不写 C 代码，但我设计了数据交换层，让 C 和 Java 能对话。技术经理的价值不是写了多少代码，是在正确的边界上做了正确的决策。"

#### 成果二：交收场景化改造 — 把参数收敛成场景（STAR 场景一）

| 问题 | 方案 | 结果 |
|------|------|------|
| 客户差异全靠参数开关实现，光交收就有先合同后款/先款后合同两类，参数越加越多、组合失控，改一个不知道波及哪条链路，新客户先配几百个参数 | 参数收敛成交收场景（款到发货/货到付款/定金+尾款/分期付款/信用证），场景内封装参数组合 + 校验规则 + 状态流转，运营按场景选不裸调；不变部分抽统一引擎（策略模式 + 规则配置）；老客户三条链路双跑对账 | 新客户上线 **2 个月 → 1 周**，参数不再膨胀，主链路无定制分支 |

> **金句**："客户要的不是一百个参数开关，而是'先款后合同'这句话背后的完整交收场景。"

#### 成果三：跨月长事务一致性 — 三年零资金差错（STAR 场景二）

| 问题 | 方案 | 结果 |
|------|------|------|
| 一笔交易跨 1-3 个月、十几个状态，每状态同步 4-6 个系统，早期点对点调用，超时就"钱扣了单没成" | 状态机（前置条件/事件/副作用/超时）+ Saga（正向+幂等补偿）+ Kafka 事件 + 本地消息表 + T+1 对账兜底 | 运行三年**零资金差错**，对账差异率从行业常见的 8% 降到 0.1% 以下 |

> **金句**："能跑的状态机一个月够，不会出事的状态机要两年——因为你要见过所有异常，才知道补偿路径怎么写。"

#### 成果四：管理三件套 — 从救火队长到技术领导者

| 机制 | 做什么 | 效果 |
|------|--------|------|
| On-call 轮值 | 主副双岗按周轮换，P0-P3 四级 SLA | 团队独立处理 80% 线上问题，凌晨被叫起月均 8 次 → 2 次 |
| 技术债台账 | 债务项 / 风险 / 成本 / 优先级可视化 | 隐性债务 → 显性 → 可控 |
| 20% 带宽原则 | 每迭代固定 20% 产能还债 | 被动响应占比 **45% → 15%** |

> **金句**："临时方案不可怕，没有退路、没有记录、没有终点的临时方案才可怕。"

#### 成果五：场景化工作台 — 从"功能菜单"到"任务向导"

| 问题 | 方案 | 结果 |
|------|------|------|
| 左侧导航几十个入口，客户不知道点哪里，新客户培训要半天 | 按任务组织界面：我要买货/我要卖货/我要发货/我要对账，一个任务一条线性引导流 + 角色视图自动过滤 | 培训 **半天 → 30 分钟**，客服咨询量下降 60% |

> **金句**："客户来平台是带着明确任务来的，不是来'逛'的。按功能堆菜单，等于把说明书甩给客户自己研究。"

**三个杀手标签**

1. **异构架构** — C + Java + Vue 四层分层，市场稀缺
2. **业务深度** — 懂大宗全链路，不只懂技术
3. **管理转型** — 从救火到主动，用机制替代亲力亲为

**四层架构（必须能脱手画）**

```
接入层（PC / 移动 / 大屏 / 机构 API）
  ↓
网关层（midservice 管"请求怎么进" + midmon 管"系统怎么样"）
  ↓
数据交换层（DS 防腐层 TCP↔Hessian / Kafka 事件 / Canal+缓存 / 外部生态适配）
  ↓
业务层（Java 微服务中台 + C 单线程内存撮合内核）
```
