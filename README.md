# 面试工作台 interview-kit

B2B 技术经理求职材料库：八股题库、备战手册、实战案例、简历站点，入口为本地工作台。

- 入口：`index.html`（面试工作台 App）
- 启动：双击 `start.bat` → http://127.0.0.1:3001
- 桌面端侧边栏含「案例 · 场景」页：四类客户复盘 + 一笔交易十个业务场景 + 案例/场景资料清单（移动端底部导航保持 5 项，该页仅桌面可达）

## 目录

| 目录 | 内容 |
|------|------|
| `prep/` | **材料库主目录**（唯一资料库）：`00-资料库总览` 索引 + `01~08` 分类，入口 `prep/index.html`（左侧文件树 + 右侧预览） |
| `prep/01-产品定位` | 平台功能、角色与业务动作全景、设计规范、产品全业务链条 |
| `prep/02-业务价值` | 业务全链路场景、痛点体系、价值论证、期现结合、供应链 B2B 与金融方案分析 |
| `prep/03-架构决策与问题排查` | 架构方法论与选型、异构架构、多租户治理、六大难点、Saga、Cookie 认证失败 5Why、技术整改十项 |
| `prep/04-案例与投递` | 数字产业链演示稿、客户案例、简历 PPT 与能力全景介绍 |
| `prep/05-职业发展` | 技术经理成长体系、进阶路线图、跨部门沟通 |
| `prep/06-面试准备与模拟对练` | 面试策略、技术题库、问答话术、背诵手册、模拟面试方案与提示词、快速通览一页纸简报、技术经理双能力体系、四类客户复盘、面试训练框架与计划 |
| `prep/07-八股题库` | 技术知识点题库：`01-八股文与深度整理`（Java/MySQL/Redis/Nginx/Kafka/Linux/Tomcat/网络）+ `02-面试真题`（架构师/Java/运维/项目经理等） |

| `slides/` | 数字产业链服务平台 PPT 截图（170 页）+ 翻页器 `slides/index.html` |
| `resume/` | 简历与项目实战经验站点（浏览器打开 `resume/index.html`） |
| `tools/` | 全部生成脚本（题库 HTML / 背诵集合 / PPT / docx），用法见 `tools/README.md` |

## 约定

- **单一信息源**：同一主题只维护一份权威 `.md`，其他文件只引用；派生件加后缀 `.mobile.html` / `.visual.html` / `.print.html` / `.slides.pptx` / `.pdf`。同源派生件应先尝试合并为**单个响应式 `.html`**（无额外后缀），确有排版差异时才拆分为 `.mobile` / `.visual`。
- **命名**：目录与目录内文件均用 `NN-主题`，两组编号各自独立。
- **分类维度**：`prep/01–06`、`08` 按备战维度（讲什么、何时用）；`prep/07-八股题库` 按技术主题（知识点检索），两者正交不混编。

## 边界

- AI 课程 / LLM 刷题 → `personal-tech-knowledge/ai-study/`
- 架构知识长文 → `personal-tech-knowledge/knowledge-base/`；项目叙事 → 本仓库 `prep/03-架构决策与问题排查/` 与 `prep/06-面试准备与模拟对练/`
- 题库 HTML 由 `tools/md2html.py` 重建，源文件以 `.md` 为准
