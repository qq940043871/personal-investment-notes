## 约定

- **单一信息源**：同一主题只维护一份权威 `.md`，其他文件只引用；派生件加后缀 `.mobile.html` / `.visual.html` / `.print.html` / `.slides.pptx` / `.pdf`。同源派生件应先尝试合并为**单个响应式 `.html`**（无额外后缀），确有排版差异时才拆分为 `.mobile` / `.visual`。
- **命名**：目录与目录内文件均用 `NN-主题`，两组编号各自独立。
- **分类维度**：`00-面试计划/` 按备战维度组织（讲什么、何时用）；`01-个人简历/` 收简历与配套材料；`04-技术管理/`（团队 / 流程 / 效能 / 整改 / 稳定性）独立成根级目录；`03-技术真题` 按技术主题（知识点检索），两者正交不混编。
- **路径**：工作台与各门户统一使用仓库根相对路径（如 `00-面试计划/10-面试训练手册.md`），新增资料按所属菜单目录落位。

## 边界

- AI 课程 / LLM 刷题 → `personal-tech-knowledge/ai-study/`
- 架构知识长文 → `personal-tech-knowledge/knowledge-base/`；项目叙事 → 本仓库 `02-现货贸易/03-架构决策/` 与 `00-面试计划/`
- 题库 HTML 为 `.md` 的派生件，源文件以 `.md` 为准（PPTX 构建脚本在 `01-个人简历/07-面试介绍PPT/`：`build-deck.mjs` / `build-intro.mjs` 为主脚本，`deck-kit.mjs` 为共用组件）
