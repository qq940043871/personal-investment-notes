# 面试工作台 · interview-kit

B2B 技术经理 + AI 智能体双线求职材料库：面试计划、现货贸易业务与架构底稿、AI 智能体业务设计、技术真题、技术管理。入口为本地工作台 App（单文件 `index.html`，无构建、无后端）。

- 入口：`index.html`（工作台，11 个菜单：首页 / 面试计划 / 现货贸易 / AI 智能体 / 技术真题 / 技术管理 / 备战手册 / 现货经验线 / AI 经验线 / 案例 · 场景 / 我的）

- 发布：仓库含 `.nojekyll`，可直接挂 GitHub Pages 作静态站点

## 工具与脚本

| 脚本 | 用途 |
|------|------|
| `tools/md2html.py` | 题库 md → html 按需单篇导出（md 为唯一事实源；仓库不再保留批量派生件） |
| `tools/format_md.py` | Markdown 批量排版：补全代码块语言标识、压缩代码块外空行，不改正文 |
| `tools/verify_md.py` | 排版安全性校验：比对备份与处理后文件，只允许空行与代码块开标签的增删 |
| `tools/serve.js` | 本地静态服务脚本（`start.bat` 之外的 Node 直启方式） |
| `start.bat` | 本地静态服务器（3001） |
| `02-现货贸易/03-问题排查/jvm_diag.sh` | 现场一键采集 JVM / GC / 句柄 / 连接诊断包 |

## 约定

- **单一信息源**：同一主题只维护一份权威 `.md`，其他文件只引用；派生件加后缀 `.mobile.html` / `.visual.html` / `.print.html` / `.slides.pptx` / `.pdf`。同源派生件应先尝试合并为**单个响应式 `.html`**（无额外后缀），确有排版差异时才拆分为 `.mobile` / `.visual`。
- **命名**：目录与目录内文件均用 `NN-主题`，各目录编号独立；每个功能目录根放 `README.md` 或 `00-*索引 / 00-导航` 作该目录唯一入口。
- **分类维度**：`00-面试计划/` 按备战维度组织（讲什么、何时用）；`02-现货贸易/` 按「业务 → 技术 → 排查」分层；`02-AI智能体/` 只收业务设计；`03-技术真题/` 按技术知识点检索；`04-技术管理/`（团队 / 流程 / 效能 / 整改 / 稳定性）独立成根级目录，与其他维度正交不混编。
- **路径**：工作台与各门户统一使用仓库根相对路径（如 `00-面试计划/10-面试训练手册.md`），新增资料按所属菜单目录落位；新增根级目录要同步本 README 与 `index.html`。
- **不入库**：`.workbuddy/`（本地工作状态与过程脚本）、`.codebuddy/`、`__pycache__/`、`_tmp_mysql_index/`、`_fmt_analysis.txt`、`tools/backup/`，见 `.gitignore`。
