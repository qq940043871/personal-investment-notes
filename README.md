B2B 技术经理求职材料库：个人简历、项目底稿、技术真题、备战手册，入口为本地工作台。

- 入口：`index.html`（面试工作台 App）
- 启动：双击 `start.bat` → http://127.0.0.1:3001
- 顶层目录与首页菜单一一对应：`00-面试计划` / `01-个人简历` / `02-项目底稿` / `03-技术真题` / `04-备战手册`（另附 `ai/` AI 方案集、`_archive/` 历史存档）

## 约定

- **单一信息源**：同一主题只维护一份权威 `.md`，其他文件只引用；派生件加后缀 `.mobile.html` / `.visual.html` / `.print.html` / `.slides.pptx` / `.pdf`。同源派生件应先尝试合并为**单个响应式 `.html`**（无额外后缀），确有排版差异时才拆分为 `.mobile` / `.visual`。
- **命名**：目录与目录内文件均用 `NN-主题`，两组编号各自独立。
- **分类维度**：`04-备战手册/01`–`06`（`05` = 技术管理：团队 / 流程 / 效能 / 整改 / 稳定性）按备战维度（讲什么、何时用）；`03-技术真题` 按技术主题（知识点检索），两者正交不混编。
- **路径**：工作台与各门户统一使用仓库根相对路径（如 `04-备战手册/06-面试准备/06-面试话术与背诵手册.md`），新增资料按所属菜单目录落位。

## 边界

- AI 课程 / LLM 刷题 → `personal-tech-knowledge/ai-study/`
- 架构知识长文 → `personal-tech-knowledge/knowledge-base/`；项目叙事 → 本仓库 `04-备战手册/04-架构决策/` 与 `04-备战手册/06-面试准备/`
- 题库 HTML 为 `.md` 的派生件，源文件以 `.md` 为准（PPTX→HTML 转换脚本在 `04-备战手册/_build/`：`pptx2html.py` 为主脚本，`verify_content.py` / `verify_html.py` 为校验脚本）
