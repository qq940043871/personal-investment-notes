# 面试工作台 interview-kit

B2B 技术经理求职材料库：八股题库、备战手册、实战案例、简历站点，入口为本地工作台。

- 入口：`index.html`（面试工作台 App）
- 启动：双击 `start.bat` → http://127.0.0.1:3001
- 桌面端侧边栏含「案例 · 场景」页：五类客户复盘 + 一笔交易十个业务场景 + 案例/场景资料清单（移动端底部导航保持 5 项，该页仅桌面可达）

## 约定

- **单一信息源**：同一主题只维护一份权威 `.md`，其他文件只引用；派生件加后缀 `.mobile.html` / `.visual.html` / `.print.html` / `.slides.pptx` / `.pdf`。同源派生件应先尝试合并为**单个响应式 `.html`**（无额外后缀），确有排版差异时才拆分为 `.mobile` / `.visual`。
- **命名**：目录与目录内文件均用 `NN-主题`，两组编号各自独立。
- **分类维度**：`prep/01`–`04`、`06`、`09` 按备战维度（讲什么、何时用）；`prep/05-八股题库` 按技术主题（知识点检索），两者正交不混编。

## 边界

- AI 课程 / LLM 刷题 → `personal-tech-knowledge/ai-study/`
- 架构知识长文 → `personal-tech-knowledge/knowledge-base/`；项目叙事 → 本仓库 `prep/04-架构决策/` 与 `prep/06-面试准备/`
- 题库 HTML 为 `.md` 的派生件，源文件以 `.md` 为准（PPTX→HTML 转换脚本在 `prep/_build/`：`pptx2html.py` 为主脚本，`verify_content.py` / `verify_html.py` 为校验脚本；md→html 重建脚本仍缺失，见 `prep/00-资料库总览.md` 第五节）
