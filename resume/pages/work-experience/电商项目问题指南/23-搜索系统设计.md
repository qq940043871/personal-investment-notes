# 23 - 搜索系统设计

> 如何用 Elasticsearch 构建全文检索与搜索能力

---

## 📖 概述

本章介绍 Elasticsearch、搜索优化、推荐系统。

> **口径说明**：以下内容区分「本人真实做过」与「通用方案/行业知识」。

---

## 个人经验锚点

| 分类 | 内容 |
|------|------|
| **真实做过** | **Elasticsearch 落地**：在 **B2B 大宗交易平台**用 ES 做商品/货源、合同、客户等业务数据的**全文检索与多条件筛选**；索引结构设计（`keyword` + `text` 多字段）、中文分词、Canal CDC 将 MySQL 数据同步到 ES 保证准实时；查询侧做了分页/排序优化 |
| **通用方案/行业知识** | 大规模电商搜索（千万级商品、多路召回 + 粗排/精排）、**个性化推荐系统**（协同过滤/向量召回/机器学习排序）、搜索意图理解与同义词体系 —— 属行业参考，本人**未做推荐系统实战**，也未做过超大规模商品搜索 |

## 📝 二、搜索配置

### 2.1 索引设计

```json
PUT /products
{
  "settings": {
    "number_of_shards": 3,
    "number_of_replicas": 1,
    "analysis": {
      "analyzer": {
        "ik_analyzer": {
          "type": "custom",
          "tokenizer": "ik_max_word"
        }
      }
    }
  },
  "mappings": {
    "properties": {
      "id": { "type": "keyword" },
      "name": { 
        "type": "text",
        "analyzer": "ik_max_word",
        "fields": {
          "keyword": { "type": "keyword" }
        }
      },
      "category_id": { "type": "keyword" },
      "price": { "type": "scaled_float", "scaling_factor": 100 },
      "sales": { "type": "integer" },
      "create_time": { "type": "date" }
    }
  }
}
```
