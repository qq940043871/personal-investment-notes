# 17 - 安全防护体系

> 如何保障系统安全

---

## 📖 概述

本章介绍 XSS、SQL 注入、CSRF 防护等安全措施。

---

## 个人经验锚点

| 分类 | 内容 |
|------|------|
| **真实做过** | **B2B 大宗交易平台**：接口幂等（Redis/Redisson + 幂等键）、外部集成网关的接口签名与验签（对接 5 家银行 / 物流 WMS / 税务 / 电子签章 9+ 外部系统）、登录鉴权与多租户数据隔离、资金类操作的防重放与操作留痕；对 XSS/SQL 注入做预编译与参数校验为常规落地 |
| **通用方案/行业知识** | DDoS 高防清洗、WAF 规则运营、风控反欺诈模型、全站 HTTPS 证书体系化治理 —— 属行业通行方案，本人未主导过大规模安全攻防体系 |

---

## 🛡️ 一、常见攻击

| 攻击 | 说明 | 防护 |
|------|------|------|
| **XSS** | 跨站脚本攻击 | 转义/过滤 |
| **SQL注入** | 恶意SQL执行 | 预编译 |
| **CSRF** | 跨站请求伪造 | Token |
| **DDoS** | 分布式拒绝服务 | 限流/清洗 |

---

## 🔒 二、接口幂等

```java
// 接口幂等注解
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Idempotent {
    long expireSeconds() default 60;
}

// 幂等拦截器
public class IdempotentInterceptor {
    public boolean preHandle(String key) {
        return redisTemplate.setIfAbsent(key, "1", 60, TimeUnit.SECONDS);
    }
}
```
