## 第四章 技术路线与关键技术
- 4.1 技术选型总览（选型原则：成熟主流、自主可控、信创友好、生态活跃）
  - 4.1.1 前端技术栈
    - 管理后台与会员门户：Vue 3 + TypeScript + Vite + Element Plus
    - 微前端架构：qiankun（交易子系统独立部署、增量升级）
    - 数据大屏/行情可视化：ECharts + DataV（K线图、行情滚动、驾驶舱）
    - 移动端：uni-app（一套代码发布 H5 / 小程序 / App）
  - 4.1.2 后端技术栈
    - 开发语言与框架：Java 17 + Spring Boot 3 + Spring Cloud Alibaba
    - 微服务治理：Nacos（注册/配置中心）、Sentinel（熔断限流）、Gateway（网关）、Seata（分布式事务）
    - 撮合引擎：Netty 长连接 + 内存撮合 + 异步落库（支撑秒级撮合、万级并发报价）
    - 定时任务：XXL-Job（行情采集、结算跑批、对账）
  - 4.1.3 数据存储
    - 关系型数据库：MySQL 8（主从 + 读写分离）｜信创替代：达梦 DM8 / 人大金仓 KingbaseES
    - 缓存：Redis Cluster（行情热点、会话、分布式锁 Redisson）
    - 搜索引擎：Elasticsearch（订单检索、日志分析）
    - 文档存储：MongoDB（合同附件、非结构化单证）
    - 时序数据：TDengine / InfluxDB（行情 Tick 数据、指数计算）
    - 数据仓库：Greenplum / StarRocks（经营分析、监管报表）
  - 4.1.4 中间件与集成
    - 消息队列：RocketMQ（交易事件、削峰填谷）+ Kafka（行情广播）
    - 服务间通信：OpenFeign（同步）+ gRPC（撮合内部高性能链路）
    - 接口网关与开放平台：统一 API 网关 + OAuth2.0 授权（对接银行/监管/税务/物流）
    - 电子签章：CFCA / e签宝（占位，按招标要求）
  - 4.1.5 DevOps 与云原生
    - 容器化：Docker + Kubernetes（私有化部署同样适用）
    - CI/CD：GitLab + Jenkins / GitLab CI
    - 监控告警：Prometheus + Grafana（指标）、SkyWalking（全链路追踪）、ELK（日志）
  - 4.1.6 信创国产化适配矩阵（一张表）
    | 层次 | 通用选型 | 信创替代 | 兼容策略 |
    |------|---------|---------|---------|
    | CPU | x86 | 鲲鹏 / 飞腾 / 海光 | 多架构镜像 |
    | 操作系统 | CentOS / Ubuntu | 麒麟 V10 / 统信 UOS | 双栈构建 |
    | 数据库 | MySQL 8 | 达梦 DM8 / 金仓 | ORM 层方言适配 |
    | 中间件 | Redis / RocketMQ | 东方通 / 宝兰德（含） | 配置级切换 |
    | 浏览器 | Chrome | 奇安信 / 360 安全浏览器 | 前端兼容性测试项 |
- 4.2 高并发交易关键技术（竞价高并发、分布式锁、削峰、秒级撮合）
- 4.3 信创国产化适配（国产 CPU / 操作系统 / 数据库 / 中间件 兼容矩阵）
