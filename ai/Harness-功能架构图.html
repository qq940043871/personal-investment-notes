① 口径声明：本图为 Agent Harness 的个人技术储备形态（Python + FastAPI 承载 MainLoop，客户端 PyQt6 / Vue3）│它不属于公司平台技术栈（公司侧为 Java 微服务业务中台 + C 语言单线程内存撮合引擎）。

② 分层原则：二 · 编排层是心脏，决定"走到哪一步"│三 · 工具层定义"能做什么"│四 · 状态层保证"能断能续"│五 · 治理层保证"不越权、可停"│六 · 观测层保证"看得见"。

③ 一条主轴：模型只吐 tool_calls（一段 JSON）│解析、校验、审批、执行、回灌全在 Harness——模型从头到尾不知道 MCP 是什么。
