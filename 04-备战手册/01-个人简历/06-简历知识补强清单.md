## 零、先看简历的四个风险（这个比补知识更急）

### 风险 1：AI 段与你的真实口径严重冲突 ⚠️ 最急

简历里写的是：

**处理方式（二选一，见第五节的具体文案）**：面试时主动右尺寸化，把 AI 讲成"选型 + 解析链路改造"，而不是"核心技术攻关"。

## 二、P0 必补详解

### 2.1 AI 应用与智能体（→ 直接读 `15-AI工程能力补强手册`）

**为什么是 P0**：简历里 AI 是**独立一段经历 + 一个项目条目**，写得比谁都重。面试官必挖。

**会问到的深度（三层）**：
- 第一层：RAG 是什么、LangChain 干嘛的 → 你答得上；
- 第二层：RAG 效果不好怎么排查、切块策略怎么选 → 补 `15-手册`§四；
- 第三层（**致命层**）"你说的智能体记忆/工具调用不稳定，具体怎么解决的" → **这层你没真实经历**，必须用**诚实话术**接（见第五节）。

**补强动作**：`15-手册`通读 + `08-AI真题` Q30-Q72（RAG 34 题 + Dify/中台集成 9 题）、Q73-Q113（Agent 应用设计 25 题 + Harness 运行时 16 题，JD 六机制重点看 Q98-Q113）过一遍；重点准备"**我没有深做过，但我理解它的机制**"的答法。

### 2.2 网关三大机制：路由 / 限流 / 熔断（简历写了"精通"）

**为什么是 P0**：你自己写的"**精通**核心机制"——这是**主动邀请**对方深挖。

**必须能答到第二层的点**：
- **限流算法**：固定窗口（有临界突刺）、滑动窗口、漏桶（恒定速率、可缓冲）、**令牌桶**（允许突发）；**分布式限流** = Redis + Lua 原子脚本（单机限流在多实例下失效——这是必问点）。
- **熔断**：状态机 **Closed → Open → Half-Open**；触发条件（错误率 / 慢调用比例）；半开态试探恢复；工具：Sentinel / Hystrix / Resilience4j。
- **降级**：失败返回兜底（默认值 / 缓存 / 友好提示），**限流-熔断-降级的先后关系**。
- **隔离**：线程池隔离 vs 信号量隔离。
- **路由**：动态路由、权重灰度、按租户路由。

**库里现状**：`02-技术栈全景图` Q1-Q3 有网关问答，但**偏"你们自研网关"的叙事**，算法细节需自查补。**建议补一份"限流/熔断/降级 20 问"**。

### 2.3 高并发与故障根治（简历写了"擅长"）

**会问到的深度**："QPS 10 倍怎么扛"（答案要分层：前端缓存 → CDN → 网关限流 → 应用无状态扩容 → 缓存 → DB 读写分离/分库分表 → 异步削峰）；"你**根治**过的最大故障"（要 5Why + 防再发机制 + 进手册闭环）。

**库里现状**：✅ 很全——`11-网关扩容打穿DB`（五层防线）、`12-生产排查步骤`（六步 SOP）、`09/10` 排查实录。**把这几篇的"五层防线 + 六步 SOP"背成肌肉记忆即可**。

### 2.4 平台-应用协同：配置 / 编排 / 扩展 / 定制

**为什么 P0**：这是目标岗位最独特的一条（JD 职责 2）。你的多租户配置化经验**正好对应**，但简历里**没写成这个术语**。

**话术**：配置 → 编排 → 扩展 → 定制**四个台阶**，能用低台阶绝不用高台阶（详见 `13-超聚变`§3.4 金句 1）。材料：`02-现货贸易/03-架构决策/03-平台化治理与多租户架构手册`。

### 2.5 分布式事务与一致性（清算 / 供应链金融背景躲不掉）

**会问到的深度**："下单扣库存 + 扣额度 + 创建合同，怎么保证一致"——要能讲**方案演进**：2PC/XA → TCC → **本地消息表 / 事务消息** → **Saga**（长事务补偿）；以及 CAP/BASE、**幂等设计**（幂等键、去重表）。

**库里现状**：✅ `02-现货贸易/03-架构决策/05-Saga编排器` + `02-技术栈全景图`§五"分布式事务"。

### 2.6 确定性与 AI 分层 / 安全边界

**为什么 P0**：目标岗位任职要求 6 的原文考点，多数候选人只会背概念。

**答法**：跟钱 / 合规 / 状态强相关的（对账、资金计算、状态流转、权限）走**确定性逻辑**，AI 不碰写路径；AI 只做非结构化理解、检索汇总、草稿建议。三道边界：安全 / 质量 / 运行。材料：`15-手册`§七、`13-超聚变`§四 C4。

## 四、P2 加分 / 补盲区

### 4.1 制造业信息化域（目标公司盲区）⭐ 建议优先于其他 P2

超聚变是**制造企业**。若面试官聊到"领域内信息系统"，会涉及：**IPD**（集成产品开发主流程）、**MES**（制造执行）、**PLM**（产品生命周期）、**SRM**（供应商关系）、**ERP**（你熟的是业务侧，制造侧要补概念）。

**补强动作**：一页"**制造数字化域词典**"——每个系统管什么、上下游关系、典型痛点。不需要精通，需要**能听懂、能接话**。

### 4.2 区块链 / Web3（简历整段，库里覆盖薄）

简历写了一个完整项目（智能合约 / 上链 / 验签 / DID / 分布式账本 / 链上确权）。**会被问**："你们为什么用区块链而不是数据库？"（答：多方互不信任场景下的**可信第三方替代**——多方共治、不可篡改、可追溯）；"共识机制了解吗"（PoW/PoS/PBFT 一句话）；"DID 是什么"（去中心化身份）。

**建议**：补一份"区块链 10 问基本盘"，能讲清**业务动机**比讲清技术细节重要。

### 4.3 数据与指标质量体系

你在清算 / 对账上的实力（三流匹配、口径统一）**本质就是数据质量**，但简历没用这个术语。补一套话术：数据质量四维（准确/完整/及时/一致）+ 你的对账引擎 = "一致性"域的生产实践。

### 4.4 架构方法论框架

TOGAF / **C4 模型**（画架构图的统一语言）/ 4+1 视图 / ATAM 评估 / **ADR**（架构决策记录）。**不是要你背框架，是要你能用"标准语言"描述架构**——面试官听到"我用 C4 的容器图看系统边界"会觉得你专业。
