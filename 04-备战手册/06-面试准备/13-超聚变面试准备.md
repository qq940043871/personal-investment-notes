## 零、一句话结论

**匹配度高，值得重仓准备。** 这份 JD 的三条主线，我手里都有现货：

| JD 主线 | 我的对应资产 | 现成度 |
|---------|------------|--------|
| ① 企业应用架构：系统边界、能力划分、数据模型、集成关系 | C+Java 异构四层架构 + DS 防腐层 + 业务-技术映射地图 | ★★★★★ 13 年日常 |
| ② 平台-应用协同：能力复用、接口规范、避免重复建设与过度耦合 | 多租户配置化引擎（一套引擎+每客户一套配置）+ 接口契约治理（管连线不管黑盒）+ 外部集成统一适配层 | ★★★★★ 直接对应 || ③ AI 融合架构：模型接入、知识检索、Agent Harness、工具调用、可控可评估可运维 | AI 平台底座选型复盘（Dify vs 自研）+ MinerU 文档解析改造（RAG 入口）+ 个人 Agent Harness（储备）+ 144 题 AI 题库 | ★★★☆☆ 真实参与=选型+解析层，非全链路；按 JD 术语对齐 |
**四个风险点要主动管理**：
1. **行业跨度**：大宗贸易 → 服务器/算力制造。要有"能力迁移"叙事，不是逃离行业（§3.3 战略钩子版）。
2. **华为系节奏**：面试官多为华为系出身、社招约四轮、每轮重点问最近一份工作、2 分钟自我介绍每轮都用（§1.3）。姿态要"稳"：讲机制、讲 trade-off、讲闭环（参考 `07-国企面试焦点分析.md` 的表达方式，但不要照搬国企话术）。
3. **AI 会被拷打到生产级细节**：JD 要求 5 写得非常具体（任务执行循环、状态管理、权限控制、异常恢复、人工介入、评测观测）——面试官大概率拿自己踩过的坑来问。好在 `08-AI开发工程师面试真题.md` 144 题 + `15-AI工程能力补强手册.md` 里这些点全有，需要的是按 JD 术语重排，并**守住真实参与边界**。
4. **⚠️ AI 参与边界（本文件最高优先级红线，已同步修订全文）**：公司 AI 项目里我的真实参与 = **前期技术选型（Dify vs 自研）+ MinerU 文档解析改造（PDF→Markdown）+ 多格式文档落向量库**；后续智能体落地、上下文工程、执行循环**主要由团队推进，我后期参与少，一律不夸大**。个人项目（LangGraph 6 节点流水线 / Agent Harness / 绘本智能体）**一律标"个人储备"**，绝不说成公司项目。**华为系四轮必问最近项目，任何"技术负责人 / 全链路落地"的表述都撑不过第二层追问——宁可主动收窄，不可被问穿。**

### A. 架构与平台协同类

**A1. 介绍你负责的系统，边界和数据模型怎么设计的？**

### C. AI 融合架构类（JD 分量最重，预计占面试 40%；**我的姿态：弱化 AI、主推架构**——AI 只讲"选型 + 集成架构"，不装算法）

**C2. Agent Harness 怎么设计？（JD 点名六机制）**
- 骨架（六机制逐条，用自己项目讲）：
  1. **任务执行循环**：MainLoop——感知→规划→行动→观察循环，步数/预算/超时/无进展四闸门防失控（Q77 失控模式/Q103 闸门实现，循环机理 Q80，四层划界 Q98、自研九模块 Q99）；
  2. **状态管理**：会话状态外置（Redis/DB），三态分离 + checkpoint 步步落盘，步与步之间可恢复、可回放、turn 防重（Q104；会话关联业务单据 Q71）；
  3. **权限控制**：工具分级——只读/写/高危，高危需显式授权，鉴权跟着用户身份走不跟着 Agent 走；工具注册表 annotations 与审批策略联动（Q106；工具鉴权 Q67、身份收口 Q68）;
  4. **异常恢复**：错误二分（可重试/不可重试）+ 重试矩阵，工具失败降级+补偿，模型输出非法 Schema→容错解析+带错误反馈重试，循环失败→熔断转人工（Q105 重试矩阵/Q78 工具报错/Q109 JSON 容错/Q26）；
  5. **人工介入**：human-in-the-loop 卡点——写操作前审批、低置信度输出转人工、操作可撤销窗口（Q86 暂停-恢复状态机/Q102 终止型工具 escalate_to_human）；
  6. **评测观测**：每步 trace 落日志、指标（成功率/步数/工具调用错误率/成本/时延）、离线评测集回归（Q88 可观测/Q89 轨迹评测/Q124-Q127 评估成本体系）。
- 弹药：Q73-Q113（Agent 应用设计 25 题 + Harness 运行时 16 题，重点 Q98-Q113）、`12` 故事 5（LangGraph 6 节点流水线 + FastAPI MainLoop Harness）。
- 追问："Agent 死循环怎么防"→ 步数/预算/超时/无进展四闸门 + 调用指纹去重 + 兜底转人工（Q103/Q102）。

**C3. RAG 效果不好怎么排查优化？**
- 骨架：先定位在哪层——检索层（召回率：切块/Embedding/混合检索/Rerank）还是生成层（Prompt/模型/上下文窗口）。给出评估集先行的方法。
- 弹药：Q35/Q83 + Q37 评估指标。

**C4. 确定性业务逻辑和 AI 能力怎么划分？（JD 要求 6，重点题）**
- 骨架（三层划分 + 三道边界）：
  - **划分原则**：跟钱、合规、状态强相关的（对账、资金计算、状态流转、权限）是确定性逻辑，AI 不碰写路径；AI 负责非结构化输入的理解（合同条款抽取/工单分类）、知识检索汇总、草稿与建议生成、辅助研判。
  - **分级上线**：AI 建议 + 人工确认 → AI 自动执行但可回滚 → 全自动（仅低风险场景）。
  - **三道边界**：安全边界（权限收口中台、输出 Schema 校验、内容安全、审计留痕）、质量边界（评测集 + 灰度 + 线上回归）、运行边界（可观测指标 + 降级预案 + 成本护栏）。
- 弹药：Q5/Q26/Q28/Q68/Q78-Q81、Q113（Guardrails 落地）、`12` 故事 5。
- 追问："模型给出错误报价造成损失谁负责"→ Q136（应急：下线场景/人工兜底/定位层）+ Q131（合规责任：AI 是工具，责任在人——所以流程里必须有人工卡点）。

**C5. AI 应用怎么评测和运维？**
- 骨架：离线（评测集分层：检索命中/生成质量/端到端）+ 在线（A/B、用户反馈闭环、badcase 回流标注）+ 可观测（QPS/时延/Token 成本/错误率/幻觉率抽检）+ 成本护栏（预算/限流/缓存）。
- 弹药：Q124-Q127（+ Agent 专项 Q88/Q89）。

**C6. 为什么用 Dify 这种平台而不是全自研？（呼应 JD"平台能力复用"）**
- 骨架：平台化思维——AI 应用基建（会话/日志/知识库/编排）是公共能力，自建等于重复建设；Dify 补齐 80% 通用能力，二开补 20% 差异；同时能讲清什么时候不用 Dify（深度定制 Agent 循环、超低延迟场景）。
- 弹药：Q13/Q139/Q16（框架选型对比 Q93、Harness 自研边界 Q98-Q99/Q112）。
- ⚠️ 别把答案绑死在 Dify 上——面试官想听的是"平台化 vs 自研"的判断框架，工具只是载体。

## 七、反问问题设计（挑 3-4 个用）

**技术层（问架构师/总监面试官）**：
1. "这个岗位服务的'领域'是哪块业务线？研发、制造、供应链还是营销服务？领域内现有的系统形态和团队是什么样？"
2. "平台团队和应用团队的边界，现在是清晰的还是有不少灰色地带？这个岗位进来，前三个月最需要解决的是什么？"
3. "AI 融合这块，现在内部已经跑着什么场景？评测和运维体系建到什么程度了？"
4. （战略求证，问高层）"看到公开报道里 Token Factory、xRAY 智能体平台、智企 ERP 这条产品线——这个岗位做的信息系统，跟对外数智产品线是什么关系？是能力上下游，还是两条独立的线？"

**管理层（问更高层面试官）**：
5. "团队现在的实施节奏是需求排队状态吗？瓶颈在架构、开发还是集成联调？"
6. "这个岗位对'落地效果'的考核标准是什么？一年后什么样的结果算成功？"

**HR 层**：
7. "岗位的常驻地点和出差节奏？"

> 反问的意图：既是姿态（关注落地而非概念），也是给自己收集判断信息（平台-应用边界是否混乱 = 岗位价值空间）。

<a id="八"></a>
## 八、雷区与注意事项
1. **AI 不讲概念，且守住边界**：每提一个 AI 词（RAG/Agent/Harness/评测），必须跟一个工程细节或自己的实例；且**只讲真实参与的选型与解析层**，编排/循环/上下文一律说"团队推进、我后期参与少"。超聚变是"算力公司做 AI 应用"，面试官大概率真懂——吹得越满，露馅越快。
2. **不贬低存量**：超聚变内部系统是历史演进产物，评审类问题答案一律"存量不丢、增量可控"（`07-国企面试焦点分析` 第四部分禁忌表全部适用）。
3. **行业跨度不回避**：主动讲迁移逻辑（§3.3），等面试官质疑就晚了。
4. **Dify 不当唯一经验**：平台化思维优先于工具绑定，"什么时候不用 Dify"要能答（Q13）。
5. **口径纪律**（全库统一）：13 年 = 2 清算 + 11 本司；20 人 = 3C/6Java/5Vue/5测试；所有指标带"当时设定的团队目标"限定；FastAPI/Python 只作为个人 Agent Harness 储备，绝不混入平台技术栈；客户不报名单。
6. **奋斗者文化表态要真实**：不唱高调也不抱怨，讲机制保效率（§E2）。
7. **薪资谈判**：郑州园区岗位 vs 远程/外派先问清；超聚变体系内职级与薪资带宽提前摸底。
