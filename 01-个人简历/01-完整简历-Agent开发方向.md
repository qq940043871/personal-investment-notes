### Agent Harness 运行时骨架（个人工程 · 跟课实现）

- MainLoop：Think → Act → Observe 循环引擎，五种执行状态（运行中 / 完成 / 达到轮次上限 / 出错 / 停止）与优雅中断、事件驱动扩展；工具注册表与权限分级白名单、middleware 拦截链与容错恢复、会话管理与上下文压缩、成本追踪与 benchmark 套件。
- 典型实例：微信公众号 6 节点流水线（采集 → 清洗 → 生成 → 配图 → 排版 → 发布）。
