政策解读（通用 + 电力垂直）

Policy Interpretation Agent — 时效、效力位阶、权限边界、引用真伪用代码算，只有「翻译成人话」交给大模型

价值出口 · 价值最硬 六层架构 + 两道闸门 电力垂直版 引用已废止文件 = 误导

口径声明：本页描述的是政策解读的整体设计方案（六层架构 + 两道闸门）。个人参与 = 方案选型与解析链路；规则判定逻辑由 Dify Code 节点实现，编排与规则维护由团队推进。

一条总纲（先记住这句）：

政策解读的绝大部分风险，不是模型不够聪明，而是把确定性的事情交给了模型去猜。

时效、效力位阶、权限边界、引用真伪——这四件事全都有法定规则可循，必须用代码算；只有「把条款翻译成人话」这一件事，才交给大模型。凡是看到某个环节在「让模型自己判断」，那基本就是事故的起点。

一、五个独有约束

约束 与普通知识库问答的差别 答错的后果
时效敏感普通文档是「追加新版本」，政策是「失效 / 被替代」引用已废止文件 = 误导
效力分层存在法定位阶，下位不得抵触上位拿地方试点文件否定国务院条例
条款级溯源必须落到「第 X 条第 Y 款」说「根据相关政策」= 用户无法核实
解读 ≠ 立法不得替制定机关创设规则越界解读被当成官方口径使用
权限与密级征求意见稿、内部文件有明确知悉范围泄露未公开文件，属事故

二、三条写进代码的硬规则

规则一 · 有效期

  • • 行政规范性文件有效期一般 ≤ 5 年；冠以「暂行/试行」的 ≤ 3 年
  • • 届满未明确延续的自动失效，不需要谁再发废止通知
  • • 制定机关应在届满前 6 个月组织评估
  • • 专用于废止旧文件的，不适用有效期规定

规则二 · 公布日 ≠ 施行日

  • • 一般要求施行日与公布日之间留间隔（常见 30 日）
  • • 突发、执行上级紧急命令可自公布之日起施行
  • • 推论：文件存在第三种状态——「已公布、尚未施行」
  • • 不建模这个状态、把公布日当生效日，那一类问题必错

规则三 · 法律适用

  • • 上位法优于下位法
  • • 特别法优于一般法（仅限同一机关）
  • • 新法优于旧法、变通法优于被变通法
  • • 「工作方案」「会议纪要」不构成行政管理依据 → 正确答案是如实告知，不是硬凑解读

三、六层架构 + 两道纯代码闸门

① 接入层 · 会话 · trace_id · 附件视为「待解读材料」而非指令
② 规范化层 · 口语→术语（"两个细则"→正式名称）· 文号识别 · 纠错
③ 理解层 · 意图三层判定（规则 → 轻量模型 → 保守兜底）· 槽位抽取
④ 直击层 · L0 标注 → L1 精确 → L2 语义；命中后仍过三道校验（时效/权限/替代链）
◆ 闸门 A · 权限（纯规则，检索前） · 权限画像每轮重载不缓存
⑤ 检索层 · 语义 + 关键词混合检索 · Rerank · 时效与效力校验（纯规则）
⑥ 生成层 · 受约束生成：强制 schema + 强制引用 + temp=0
◆ 闸门 B · 核验（纯规则，生成后） · 引用核验 + 越权复核
输出 + 审计 · 三档门控降级 · 未命中样本回流直击库候选池

两道闸门都是纯代码，不经模型判断。这是「企业级」与「玩具」的分水岭：模型可以决定话怎么说，但不能决定「你有没有权看」和「这个引用是不是真的」。

四、电力垂直版：六个独有难点

# 难点 通用政策没有的麻烦 翻车后果
1存在「非政府但有约束力」的一层《供电营业规则》《电力交易规则》《两个细则》由电网企业/交易中心/派出机构发布，不是政府规范性文件，却对市场主体有事实约束把企业规则当政府政策引用 → 效力定性错误
2主管机关多头且分层发改委（价格）、能源局（规划/监管）、区域派出机构、省发改委、省能源局，部分省在工信厅建议用户去错部门
3术语口语化极严重「度电」「过网费」「隔墙售电」「两个细则」全是行业黑话，且不写进正式文件按口语检索 → 关键词通道全空
4电价与时效强绑定多为「自 X 年 X 月 X 日起执行」，一年一调且带执行周期用过期电价 → 直接算错钱
5地域差异极大同是「分布式光伏并网」，各省容量上限、备案流程、补贴规则完全不同拿外省政策答本省问题
6角色决定适用条款同一件事，发电企业、电网企业、售电公司、用户看到的条款完全不同答非所问，甚至答了不该适用的条款

第 6 条最隐蔽：用户问「电价怎么算」，不知道他是发电侧还是用户侧，答案可能完全相反。所以角色是必抽槽位，不是可选。

五、降级三档：宁可少说，不可乱说

A 档 · 完整解读

条款清晰、引用核验通过：给解读 + 文号 + 条款位置 + 时效状态。

B 档 · 仅原文

检索到但不确定：只给原文摘录与出处，不替用户下判断。

C 档 · 未找到依据

如实告知 + 建议咨询渠道，不生成任何「看起来像政策」的内容。

贯穿全局一条原则：所有降级都朝「信息更少但更确定」的方向走，绝不朝「信息更多但更不确定」的方向走。这条原则反过来做，就是一份看起来很聪明、实际不能用的方案。
