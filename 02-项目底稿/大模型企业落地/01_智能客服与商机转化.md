## 二、大宗商品场景

### 2.1 典型痛点

```
客户咨询 →  → 大量专业术语（升贴水、基差、点价）
                ↓
         传统客服：培训周期长（3-6个月）
                ↓
         客户等待长 → 商机流失

AI客服介入 → 专业对话引擎 → 秒级响应（设想）
```

### 2.2 核心功能设计

#### ① 多轮专业对话（交互设计示意）

```markdown
客户：我有一批铝锭想卖
AI：
├── 理解意图：出售意向
├── 提取信息：品种=铝锭
├── 查询库存参考价
└── 回复：
    "今日长江现货铝锭报价18,800元/吨，
     您想挂牌销售还是询价？"

客户：想挂
AI：
├── 收集信息：数量、仓库所在地、期望价格
├── 对接挂牌 / 询价接口（设计）
└── 生成预览确认
```

> 上述为**交互设计示意**：报价数值、成交流程均为示例，用于说明对话形态，非系统实际输出；接口对接部分为方案设想。

#### ② 交易链路引导（方案设想）

```
1. 资质核验 → 2. 签约CA → 3. 保证金缴纳 → 4. 成交确认
     ↓              ↓             ↓              ↓
  自动核查       线上签署      余额提醒      成交推送
```

#### ③ 价格咨询与预警（方案设想）

- **主动推送**：当市场价格触发客户设置的预警线时，AI主动触达
- **点价建议**：结合客户持仓成本，生成点价时机建议
- **比价分析**：自动生成不同仓库/品类的价格对比表

## 三、电子商务场景

### 3.1 典型痛点

```
• 咨询量大（促销期间峰值10x）
• 商品品类多（SKU更新快）
• 退货率高（30~50%与客服响应慢相关）
• 差评传播快（用户晒图+长文）
```

### 3.2 核心功能设计

#### ① 智能导购（交互设计示意）

```markdown
客户：这台电脑能玩《黑神话》吗？
AI：
├── 识别：商品=笔记本电脑，游戏=《黑神话：悟空》
├── 查询配置要求：RTX 4060及以上
├── 对比商品参数
└── 回复：
    "推荐您选择 RTX 4070 显卡版本，
     具体型号链接：[跳转]
     附：游戏推荐配置 vs 本机参数对比表"
```

#### ② 差评预防与挽回（方案设想）

```
用户下单后72小时内
    ↓
AI主动关怀消息
    ↓
┌─────────────┬──────────────┐
│ 未发货      │ 物流延迟预警  │
│ 已发货      │ 预计到达提醒  │
│ 已签收      │ 使用引导 + 好评返现 │
│ 差评风险    │ 主动补偿弹窗  │
└─────────────┴──────────────┘
```

#### ③ 智能工单分类（方案设计）

| 工单类型 | AI处理方式 | 转人工条件 |
|---------|-----------|-----------|
| 物流查询 | 直接回复 | 异常情况 |
| 退换货 | 自动判定+操作 | 高价值/特例 |
| 投诉 | 情绪识别+安抚 | 3轮未解决 |
| 技术支持 | 知识库检索 | 专业问题 |

## 四、商机转化增强（方案设计）

### 4.1 转化漏斗优化（示意）

```
                    曝光量
                       ↓
                  点击咨询 (5%)
                       ↓
                  有效对话 (60%)
                       ↓
              需求确认 (40%)
                       ↓
              方案报价 (25%)
                       ↓
               成交转化 (15%)
                       ↑
        AI优化点：提升每个节点的转化率（目标）
```

### 4.2 意图识别设计（示意）

```python
# 意图分类设计示例（规则示意，非线上模型）
意图分类 = {
    "求购意向": ["想买", "怎么买", "有货吗", "报价"],
    "比价意向": ["哪家便宜", "对比", "别人多少"],
    "售后意向": ["退货", "赔偿", "投诉", "太差"],
    "合作意向": ["代理", "入驻", "渠道", "代理"]
}
```

### 4.3 商机评分（方案设计）

```markdown
设计思路：AI自动为每条线索打分

商机评分 = f(
    活跃度积分,     # 对话轮次、停留时长
    意图明确度,     # 是否明确品种/数量/价格
    信用画像,       # 企业资质、历史成交
    市场时机        # 品类行情热度
)

评分等级（设想）：
• S级 (90+) → 优先跟进，1小时内响应
• A级 (70~89) → 标准跟进，24小时内
• B级 (50~69) → 培育跟进，定期推送
• C级 (<50) → 沉默客户，低频触达
```

## 五、技术实现要点（方案设计）

### 5.1 RAG增强

```markdown
检索增强设计的知识库分层：

┌─────────────────────────────────────────────────────┐
│ 知识库分层（设计）                                 │
├─────────────────────────────────────────────────────┤
│ 层1：通用FAQ（商品介绍、售后政策）     →  高权重   │
│ 层2：品类专业知识（规格参数、价格规则） →  专业术语 │
│ 层3：企业私有知识（内部流程、特殊协议）→  权限隔离 │
│ 层4：实时行情数据（价格、库存、汇率）  →  动态获取 │
└─────────────────────────────────────────────────────┘
```

> 注：本人真实参与的是**文档解析（MinerU）→ 向量库**的数据链路，上表为在该链路上的知识库分层设想。

### 5.2 多模态能力（方案设想）

- **图片理解**：客户发图咨询商品，AI自动识别品类/规格
- **语音转写**：电话渠道自动转写+摘要
- **OCR识别**：营业执照、合同照片自动录入

### 5.3 人机协作模式（方案设计）

```
                    ┌─────────────────────┐
                    │   用户发起咨询       │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │   AI接待            │
                    │  (意图识别+知识库)  │
                    └──────────┬──────────┘
                               ↓
                    ┌──────────┴──────────┐
                    ↓                     ↓
               AI独立解决            需要人工
               (设想 60~70%)         (设想 30~40%)
                    ↓                     ↓
               工单闭环              AI预填+转接
                    ↓                     ↓
               满意度评价            人工处理+AI辅助
```
