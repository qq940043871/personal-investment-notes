## 二、页面布局规范

### 2.1 基础布局类型

B2B电商平台主要采用以下几种布局结构：

#### F型布局（信息展示型）
```
┌──────────────────────────────────────────────────────────┐
│  Logo  |           搜索框            | 用户中心 | 购物车  │
├────────┬─────────────────────────────────────────────────┤
│        │                                                 │
│ 分类   │           热门内容区（高权重）                   │
│ 导航   │                                                 │
│        ├─────────────────────────────────────────────────┤
│ 200px  │           次要内容区                             │
│        │                                                 │
│        ├─────────────────────────────────────────────────┤
│        │           底部内容区                             │
│        │                                                 │
└────────┴─────────────────────────────────────────────────┘
```

**适用场景**：资讯型B2B平台、供应商展示页面  
**转化率提升**：22%（相比随机布局）

#### Z型布局（电商导航型）
```
┌──────────────────────────────────────────────────────────┐
│  Logo  |                    搜索框                  | 购物车│
├──────────────────────────────────────────────────────────┤
│                                                         │
│            产品展示区（对角线高权重）                    │
│                                                         │
├─────────────────────────────┬──────────────────────────┤
│                            │                          │
│    次要内容（左下）          │    次要内容（右下）      │
│                            │                          │
└─────────────────────────────┴──────────────────────────┘
```

**适用场景**：B2C/B2B混合电商、分类导航页面  
**点击率提升**：18%

#### 栅格系统布局（响应式标准）
- **列数**：24列（灵活适配各种比例布局）
- **列宽**：固定Column，动态Gutter
- **公式**：总宽度 = 24×Column + 23×Gutter
- **优势**：完美支持2/3/4/5/6分比布局

### 2.2 统一设计尺寸

#### PC端设计尺寸
- **推荐分辨率**：1440×900px（适配误差最小）
- **备选分辨率**：1920×1080px、1366×768px、1440×900px
- **适配原则**：按1440设计，向下向上适配

#### 页面框架结构

```
┌─────────────────────────────────────────────────────────┐
│                    顶部栏（56px）                        │
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  侧边栏  │              主体内容区                       │
│ (200px)  │                                              │
│          │                                              │
│ 可收缩   │          动态缩放区域                         │
│          │                                              │
└──────────┴──────────────────────────────────────────────┘
```

**尺寸规范**：
- 顶部栏高度：`48 + 8n` px，常用值 **56px**
- 侧边栏宽度：`200 + 8n` px，常用值 **200px**，收缩状态 **56px**

## 三、色彩系统设计

### 3.1 色彩体系架构

B2B色彩体系由以下四类颜色组成：

#### 1️⃣ 品牌主色（Primary Color）
**定义**：产品视觉识别核心，影响产品气质与对外形象

**选型原则**：
- 理性选色（减少主观判断）
- 可扩展性（支持衍生适配色）
- 和谐搭配（视觉协调）

**工具推荐**：
- HCL色彩空间（比HSB更符合人眼认知）
- Figma插件：HCL color
- 在线工具：http://tristen.ca/hcl-picker/

#### 2️⃣ 语义色/功能色（Functional Colors）
**定义**：遵循用户色彩认知习惯的功能性颜色

**标准语义**：
| 颜色 | 语义 | 用途 |
|------|------|------|
| 绿色 | 通行/成功 | 成功提示、价格下跌 |
| 红色 | 禁止/错误 | 错误提示、价格暴涨、删除操作 |
| 橙色 | 警告/注意 | 警告提示、价格波动 |
| 蓝色 | 信息/链接 | 链接文字、信息提示 |
| 灰色 | 无效/禁用 | 禁用状态、次要信息 |

#### 3️⃣ 中性色（Neutral Colors）
**定义**：用于文本、背景、边框、分割线

**层级规范**：
```
主文本：#333333
次要文本：#666666
辅助文本：#999999
边框色：#E8E8E8
分割线：#F0F0F0
背景色：#F8F8F8
纯白背景：#FFFFFF
```

#### 4️⃣ 行业专用色（根据行业调整）

**B2B通用色彩规范（完整CSS变量）**：
```css
:root {
  /* 主色调 */

  --primary-light: #E6F7FF;        /* 浅蓝背景 */

  --primary-hover: #004999;        /* 悬停蓝 */

  /* 强调色 */
  --secondary: #FF6600;            /* 活力橙 */
  --secondary-light: #FFF7E6;      /* 浅橙背景 */

  --success: #52C41A;             /* 成功绿 */

  --error-light: #FFF1F0;

  /* 行情专用色 */
```

### 3.3 色彩使用规范

#### 页面色彩比例
```
品牌色：占页面面积 15%-20%
辅助色：占页面面积 10%-15%
背景色：占页面面积 ≤70%
强调色：按需点缀，不超过 5%
```

#### 无障碍设计
- 文字与背景对比度 ≥ 4.5:1（WCAG 2.1 AA标准）
- 重要信息对比度 ≥ 7:1（WCAG 2.1 AAA标准）
- 色盲友好：避免仅用颜色区分信息，配合图标或文字

#### 落地执行
- **设计侧**：所有色值生成样式库，设计师禁止手动调色
- **开发侧**：所有色值定义为CSS变量，代码中禁止使用具体色值
- **优势**：支持全局一键换肤，保证设计还原度

## 四、字体规范

### 4.1 字体家族选择

#### 系统字体栈
```css
/* 中文优先 */
font-family: -apple-system, BlinkMacSystemFont, 
             "PingFang SC", "Hiragino Sans GB", 
             "Microsoft YaHei", "Helvetica Neue", 
             Helvetica, Arial, sans-serif;

/* 英文优先 */
font-family: "Segoe UI", Arial, "Helvetica Neue", 
             Helvetica, sans-serif;

/* 数字强调字体 */
font-family: "DIN Pro", "Roboto", 
             "Helvetica Neue", Arial, sans-serif;
```

#### 平台字体适配
| 系统 | 中文字体 | 英文字体 |
|------|---------|---------|
| Windows | Microsoft YaHei（微软雅黑） | Arial |
| Mac | PingFang SC（苹方） | Helvetica |
| Linux | Noto Sans CJK SC（思源黑体） | Arial |

### 4.2 字号层级规范

#### B2B常用字号（8的倍数）
```
12px  - 辅助文字、标签、角标
13px  - 次要说明文字
14px  - 正文内容（推荐默认）
16px  - 副标题、强调正文
18px  - 小标题
20px  - 区块标题
24px  - 页面标题
30px  - 大标题
36px  - 一级标题（H1）
```

#### 字号使用场景

| 字号 | 用途 | 字重 | 行高 |
|------|------|------|------|
| 36px | 网站Logo、主标题 | 600 | 1.2 |
| 30px | 页面大标题 | 600 | 1.3 |
| 24px | 区块标题（H2） | 600 | 1.3 |
| 20px | 卡片标题（H3） | 500 | 1.4 |
| 18px | 副标题 | 500 | 1.4 |
| 16px | 重要正文 | 400 | 1.5 |
| 14px | 正文内容（标准） | 400 | 1.6-1.8 |
| 13px | 次要说明 | 400 | 1.5 |
| 12px | 辅助信息 | 400 | 1.5 |

### 4.3 行高与字重规范

#### 行高规则
```css
/* 标准行高公式 */
line-height = font-size + 6px（或 +8px）

/* 具体示例 */
font-size: 14px → line-height: 20px（14+6）或 22px（14+8）
font-size: 16px → line-height: 22px（16+6）或 24px（16+8）
font-size: 18px → line-height: 24px（18+6）或 26px（18+8）

/* 取值规则 */
- 数值取4的倍数
- 可根据实际情况适度调整
```

#### 字重规范（仅需3种）
```css
font-weight: 400;   /* Regular - 正文字重 */
font-weight: 500;   /* Medium - 副标题、强调 */
font-weight: 600;   /* Semibold - 标题、重要文字 */
```

**设计原则**：
- 优先通过**字重、颜色**区分内容层级
- 尽量减少字号种类（如淘宝2019年改版从11个缩减为7个）
- 避免字体大小过于接近（≥2px差距）

### 4.4 特殊文本规范

#### 价格数字
```css
.price {
  font-family: "DIN Pro", "Helvetica Neue", Arial, sans-serif;
  font-size: 18-24px;    /* 价格需要醒目 */

}
```

#### 行情数据

#### 英文正文

| 尺寸 | 高度 | 内边距 | 字体 | 圆角 | 用途 |
|------|------|--------|------|------|------|

```css

  /* 点击状态 */

  }

```

### 10.2 B2B与B2C设计区别

| 维度 | B2B设计 | B2C设计 |
|------|---------|---------|
| **设计风格** | 严谨、专业、稳重 | 活泼、时尚、吸引眼球 |
| **信息密度** | 较高，关注效率 | 适中，注重视觉 |
| **核心功能** | 搜索、询价、供应商筛选 | 浏览、加购、支付 |
| **交易流程** | 询价→报价→谈判→下单 | 浏览→加购→支付 |
| **决策周期** | 长，多人决策 | 短，个人决策 |
| **价格展示** | 区间价、面议 | 明确价格 |
| **信任建设** | 认证、资质、交易数据 | 评价、销量、售后 |

### 10.3 性能优化建议

#### 页面加载优化
- 图片压缩和懒加载
- 代码分割和按需加载
- CDN加速静态资源
- 骨架屏替代Loading动画

#### 用户体验优化
- 搜索结果预加载
- 列表页分页优化
- 表单数据本地缓存
- 操作反馈及时明确

#### 移动端优化
- 触控友好的按钮尺寸
- 简化的导航结构
- 适配不同屏幕尺寸
- 保持功能一致性

### 10.4 无障碍设计（a11y）

#### WCAG 2.1标准
- 色彩对比度 ≥ 4.5:1（文本）
- 支持键盘导航
- ARIA标签正确应用
- 屏幕阅读器兼容

#### 实施要点
- 避免仅用颜色传递信息
- 提供文本替代方案
- 保持逻辑清晰的焦点顺序
- 测试多种辅助技术
