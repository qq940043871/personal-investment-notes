# B2B大宗贸易供应链平台 — 角色与业务动作全景手册

> 整合自项目全部已有文档，按角色梳理所有业务动作，面向面试备战、架构评审、内部培训。

---

## 角色全景总览

平台涉及四大类共 15 个角色：

| 大类 | 角色 |
|------|------|
| **平台交易方** | 卖方/供应商、买方/采购商 |
| **客户企业内部** | 总经理/CEO、销售总监、销售员、财务、风控专员、仓储主管 |
| **生态服务方** | 仓储方、物流方/承运商、资金方/银行、质检机构 |
| **平台运营方** | 平台运营、平台风控、平台审核 |

---

## 通用基础动作：登录与认证（全角色）

所有平台用户共通的认证与安全动作，各角色在此基础上叠加业务权限：

| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **账号密码登录** | 用户名/手机号 + 密码登录，对接统一认证中心（token/claim 签发） |
| 2 | **短信验证码二次认证** | 高危操作（大额支付/合同签署/出金）触发二次短信验证 |
| 3 | **企业 CA 证书登录** | 管理员可开启 UKey/CA 数字证书免密登录（更高安全级别） |
| 4 | **扫码登录** | 移动端扫码登录 PC 端，企业微信/钉钉联合认证 |
| 5 | **登录设备管理** | 查看/管理已登录设备，远程踢出可疑设备 |
| 6 | **密码修改/重置** | 自主修改密码；忘记密码走短信/邮箱重置流程 |
| 7 | **登录日志查询** | 查看历史登录记录（时间/IP/设备/地点），异常登录告警 |
| 8 | **会话超时锁定** | 30 分钟无操作自动锁定，需重新验证 |
| 9 | **单点登录（SSO）** | 大客户内部系统与平台打通，一次登录多系统互通 |

## 一、卖方/供应商（平台交易方）

> 核心诉求：入驻开店、发布商品、管理订单、收款、发货、扩大客群、信用积累

### 入驻与认证
| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **企业入驻注册** | 提交三证合一营业执照 + 法人身份证 + 经办人授权书，填写企业基本信息（名称/地址/经营范围/联系人） |
| 2 | **银行账户绑定** | 绑定企业对公结算账户（支行/账号/户名），平台做小额打款验证（0.01 元打款→回填金额→验证通过） |
| 3 | **资质文件上传** | 经营许可证/生产许可证/进出口资质/品牌授权书等，按品类不同要求不同资质 |
| 4 | **电子签章注册** | 法人章 + 企业公章 + 经办人手写签名在签章平台（e 签宝/法大大）录入与激活，后续签约无需重复录入 |
| 5 | **子账号创建** | 创建企业内部角色子账号——销售员/财务/风控/仓储主管，逐账号配置业务角色+权限角色+数据可见范围 |
| 6 | **入驻审核跟踪** | 查看入驻审核进度（待初审→初审中→待复审→已通过/已驳回），驳回后补传材料重新提交 |
| 7 | **企业信息变更** | 工商信息变更后同步更新（营业执照更新/法人变更/银行账户变更），触发平台重新审核 |
| 8 | **资质年审** | 按年度更新上传最新资质文件，到期前 30 天系统自动提醒 |

### 交易前
| # | 业务动作 | 说明 |
|---|---------|------|
| 9 | **挂牌报价** | 发布商品（品种/规格/数量/价格/交货地），支持固定价/浮动价/基差点价/公式定价四种定价模式 |
| 10 | **批量调价** | 对接期货行情后，支持自动/手动批量调整挂牌价；可设"跟盘调价规则"（如"螺纹钢挂牌价 = 期货主力合约价 + 200 元/吨升水"） |
| 11 | **库存校验** | 挂牌时自动校验 WMS 实时可售库存，库存不足禁止挂牌，防止超卖 |
| 12 | **报价管理** | 查看、修改、下架、上架挂牌商品；批量操作（全选下架/品类调价） |
| 13 | **客户信用查看** | 查看潜在买方历史履约率、成交笔数、违约次数、当前授信额度 |
| 14 | **行情监控** | 实时关注品类价格走势、期货盘面、供需信息，辅助定价决策 |

### 交易中
| # | 业务动作 | 说明 |
|---|---------|------|
| 15 | **响应询价** | 接收买方询价单，在线报价/议价，支持多轮还价 |
| 16 | **参与竞价** | 作为卖方参与反向竞价（买方发标→多方投标→择优成交） |
| 17 | **合同模板选择** | 从合同模板库选择模板（国标合同/自定义合同/含对赌条款合同），系统自动填充品种/价格/数量 |
| 18 | **合同在线编辑** | 在线协同编辑合同条款（质量标准/计量方式/违约罚则/异议处理），改一版推送一版，双方可见修改历史 |
| 19 | **合同内部审批** | 发起内部审批流（法务→风控→业务总监），多级审批，超金额自动加签 |
| 20 | **电子签章签署** | 调用签章 SDK 完成合同在线签署，签章后合同不可篡改，自动存证归档至 ES |
| 21 | **合同变更** | 发起补充协议（数量增减/交期调整/收货仓库变更/价格变更），双方电子签章确认后合并为"原始合同+N个补充协议"的版本链 |
| 22 | **合同版本追溯** | 查看合同完整变更历史——原合同 + 变更单1 + 变更单2...，任一版本可回溯 |
| 23 | **保证金管理** | 查看买方保证金冻结/释放状态、保证金充足率 |
| 24 | **收款确认** | 确认预付款/进度款/尾款到账（线上自动确认 + 线下打款后上传凭证人工确认） |

### 履约中
| # | 业务动作 | 说明 |
|---|---------|------|
| 25 | **发货计划生成** | 按合同约定生成分批发货计划（批次/时间/数量/收货仓库） |
| 26 | **发货计划调整** | 因生产/库存原因调整发货节奏，推送买方确认 |
| 27 | **出库通知** | 发起出库指令，通知仓库备货装车，打印标准提货单 |
| 28 | **物流录入** | 录入/选择承运商，绑定运单号+车号/船号，买方实时可见 |
| 29 | **质检上传** | 上传出厂质检报告（化学成分/力学性能/热值等），对接第三方质检机构 |
| 30 | **交收确认** | 确认买方收货/验收完成，触发后续尾款结算 |

### 交易后
| # | 业务动作 | 说明 |
|---|---------|------|
| 31 | **结算申请** | 发起尾款结算申请，系统自动计算实提量、溢短装、价格调整后的最终结算金额 |
| 32 | **开票申请** | 发起增值税专用发票开具（品名/规格/数量/单价/税率从合同自动带入），推送财务审核 |
| 33 | **对账** | 系统自动生成对账单——合同金额 vs 实付金额 vs 已结算金额 vs 待结算余额，差异标红 |
| 34 | **收款看板** | 结算看板查看资金回笼状态——已回款/待回款/逾期未回款/坏账 |
| 35 | **交易报表** | 查看成交量/成交额/品类分布/客户分析/利润率 |
| 36 | **异议处理** | 处理买方质量异议（协商退货/折价/赔偿），所有沟通留痕 |
| 37 | **供应链金融申请** | 申请应收账款融资/存货质押融资 |
| 38 | **客户评价** | 对买方进行履约评价，影响买方信用分 |

## 二、买方/采购商（平台交易方）

> 核心诉求：找货、比价、下单、收货、付款、供应链金融

### 入驻与认证
| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **企业入驻注册** | 提交三证合一营业执照 + 法人身份证 + 经办人授权书，选择主营采购品类 |
| 2 | **银行账户绑定** | 绑定企业对公付款账户，做小额验证 |
| 3 | **信用资料提交** | 上传财务报表/纳税记录/银行流水/历史交易证明——用于平台授信评估（决定赊销额度和保证金比例） |
| 4 | **电子签章注册** | 经办人电子签章录入与激活，后续签约免重复操作 |
| 5 | **子账号创建** | 创建采购经理/财务/风控/老板等角色子账号，逐账号配置权限与数据可见范围 |
| 6 | **入驻审核跟踪** | 查看审核进度；配合补充材料 |
| 7 | **企业信息变更** | 工商变更后同步更新，触发重新审核 |

### 交易前
| # | 业务动作 | 说明 |
|---|---------|------|
| 8 | **浏览货源** | 按品种/规格/产地/交货地/交收标准搜索挂牌商品 |
| 9 | **一键比价** | 多供应商同品种价格、履约率、交货地、交期并排比较，自动标最低价和最优履约率 |
| 10 | **行情查看** | 实时行情中心查看品类价格走势、历史成交价、期货盘面对比 |
| 11 | **发布采购需求** | 发布求购信息（品种/数量/预算/交期），系统自动匹配供应商并推送 |
| 12 | **供应商评估** | 查看供应商资质、历史交易额、履约率、信用评级、客户评价 |
| 13 | **发起询价** | 对挂牌商品发起在线询价，支持多轮议价 |
| 14 | **集采拼单** | 参与集采模式，与其他小买家拼单获取批发价（系统自动合并→统一议价→分开发货） |
| 15 | **基差点价** | 先锁定基差（升贴水），择机在期货盘面点价确定最终采购价——点价指令→风控检查→执行→生成点价结算单 |
| 16 | **锁价采购** | 申请固定价格+延期提货服务（平台用期货对冲风险），锁价金额 × 锁价期限 |

### 交易中
| # | 业务动作 | 说明 |
|---|---------|------|
| 17 | **摘单/摘牌** | 确认交易，触发撮合引擎（C 语言单线程内存撮合→微秒级成交） |
| 18 | **保证金缴纳** | 按平台规则缴纳交易保证金——线上支付/银企直连转账，保证金不足无法进入合同环节 |
| 19 | **合同模板选择** | 选择合同模板（标准采购合同/含质量对赌条款），条款从订单自动带入 |
| 20 | **合同在线审核** | 逐条审核合同条款（质量标准/计量方式/违约罚则/异议处理/管辖权），异议条款在线标注 |
| 21 | **合同内部审批** | 发起内部审批流（采购经理→法务→财务总监→总经理），按金额分级审批 |
| 22 | **电子签章签署** | 调用签章 SDK 完成签署，签章完成合同生效，进入履约 |
| 23 | **合同变更确认** | 接收卖方变更协议，在线确认/驳回/协商修改 |
| 24 | **支付方式选择** | 选择结算方式——对公转账 / 银行承兑汇票 / 国内信用证 / 供应链金融（赊销） |
| 25 | **预付款支付** | 按支付计划执行首笔预付款（合同金额的 20%-30%），银企直连在线付款或线下打款后上传凭证 |
| 26 | **进度款支付** | 按发货进度支付进度款，每批到货验收后触发支付 |
| 27 | **尾款支付** | 全部到货验收后支付尾款（扣除质保金），系统自动计算溢短装调整后的最终金额 |
| 28 | **支付凭证管理** | 查看所有支付记录——已付/待付/逾期未付；上传线下打款凭证供卖方和平台确认 |

### 履约中
| # | 业务动作 | 说明 |
|---|---------|------|
| 29 | **订单跟踪** | 实时查看订单状态、发货进度、批次信息 |
| 30 | **物流追踪** | GPS 轨迹查看货物在途位置、预计到达时间、运输节点 |
| 31 | **收货确认** | App 拍照验收/签收，验收单自动归档 |
| 32 | **质检异议** | 发起质量异议——上传现场照片+第三方质检报告+文字描述→系统生成工单→自动分配处理人→24h 未处理自动升级 |
| 33 | **仓单查看** | 查看电子仓单状态（入库/在库/过户/质押/解押/出库），仓单全生命周期可追溯 |

### 交易后
| # | 业务动作 | 说明 |
|---|---------|------|
| 34 | **对账** | 系统自动匹配合同/付款/发票，差异标红 |
| 35 | **发票下载** | 下载增值税专用发票，用于进项抵扣 |
| 36 | **供应链金融申请** | 申请预付款融资（平台垫付→货到还款）/仓单质押融资（库存变现金） |
| 37 | **还款管理** | 供应链金融还款计划查看、分期还款、提前还款 |
| 38 | **复购** | 基于历史交易记录快速复购——"再来一单"自动填充品种/规格/供应商 |
| 39 | **评价** | 对供应商/交易体验进行评价（履约及时性/质量符合度/服务态度），影响供应商信用分 |

## 三、总经理/CEO（客户企业内部）

> 核心诉求：经营看板、审批流、资金总览、移动端便捷操作

| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **经营看板查看** | 每日 3-5 分钟查看：昨日成交额/在途物流/保证金占用/资金头寸 |
| 2 | **大额审批** | 移动端审批大额订单/合同/付款，超 500 万自动加签，审批意见+电子签名 |
| 3 | **资金总览** | 实时查看资金头寸、应收账款、应付账款、可用授信额度 |
| 4 | **业绩报表** | 查看成交量/成交额/利润/ROI 分析，按周期（日/周/月/季/年）切换 |
| 5 | **团队权限配置** | 按角色配好团队成员的平台权限和审批额度 |
| 6 | **风控报告查看** | 查看信用敞口、异常交易预警、客户违约风险 |
| 7 | **客户分析** | 客户分层、活跃度、流失预警、复购率 |
| 8 | **企业信息管理** | 管理企业基本资料/银行账户/子账号/资质文件 |

## 四、销售总监（客户企业内部）

> 核心诉求：客户管理、交易漏斗、业绩报表、团队复盘

| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **交易漏斗查看** | 晨会数据看板复盘，盯团队成交转化率——询价→报价→签约→成交各环节转化 |
| 2 | **业绩报表** | 按销售员/时间/品类/区域多维度查看业绩排行 |
| 3 | **客户管理** | 查看全团队客户池、跟进记录、成单率、客户生命周期 |
| 4 | **报价审批** | 审核销售员的报价单，参考系统建议价区间（期货价+历史成交价+库存水位三维模型） |
| 5 | **客户分配** | 新增客户分配给对应销售员，离职员工客户一键交接 |
| 6 | **合同审批** | 审批销售员提交的合同，超金额自动转 CEO 审批 |
| 7 | **数据分析** | 品类趋势、区域分布、季节性波动分析、竞品价格对标 |

## 五、销售员/业务员（客户企业内部）

> 核心诉求：询报价、合同管理、客户跟进、订单录入

| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **发起报价** | 向潜在买方发起报价单，系统自动关联企查查工商信息核验对方身份 |
| 2 | **客户跟进** | 所有沟通后 24 小时内录入平台——报价记录/谈判记录/电话纪要，形成客户时间轴 |
| 3 | **合同起草** | 选择模板起草合同，80% 条款自动生成，只需填品种/数量/价格/交期 |
| 4 | **合同提交审批** | 提交内部审批流，跟踪审批进度 |
| 5 | **合同跟踪** | 查看合同签署进度——我方已签/对方待签/双方已签/已生效/已归档 |
| 6 | **订单录入** | 摘单/下单，生成交易记录 |
| 7 | **物流查询** | 查看自有客户订单的物流状态，回复客户"货到哪了" |
| 8 | **历史记录查询** | 查看历史报价/谈判/合同——新人接手无缝衔接，客户资料不随人走 |
| 9 | **收款催办** | 查看应收账款，发起催办（系统自动生成催款函模板） |

## 六、财务/财务总监（客户企业内部）

> 核心诉求：对账、开票、付款审批、资金管理

| # | 业务动作 | 说明 |
|---|---------|------|
| 1 | **保证金审核确认** | 确认买方保证金到账（自动匹配银行流水），解锁后续交易流程 |

## 面试话术速查

### 被问"你们平台的入驻和注册流程是怎样的？"

> "我们平台的入驻不是简单的手机号注册，而是**企业级的 KYC 流程**。卖方和买方都需要提交三证合一营业执照+法人认证+经办人授权书，平台分三审制——初审核真伪（对接工商数据自动核验）、复审核资质（根据不同品类要求不同许可证）、终审核信用（对接企查查风险扫描+财务报表评估初始授信额度）。
>
> 同期还要完成三件事：银行账户绑定（小额打款验证）、电子签章注册（签章 SDK 录入激活）、子账号创建（企业内部按角色配权限）。整个入驻流程平均 3-5 个工作日，但**一旦入驻完成，后续交易全链路跑在线上——签约秒签、支付直达、物流可视**。前期投入的时间，在后续每一笔交易中几十倍赚回来。"

### 被问"你们平台有哪些角色？怎么设计权限的？"

> "我们平台涉及四类共 15 个角色——交易方（买卖双方）、客户企业内部（总经理/销售/财务/风控/仓储）、生态服务方（仓库/物流/银行/质检）、平台运营方（运营/风控/审核）。
>
> 权限设计用了 **RBAC + 业务角色层**双模型：业务角色（采购商/销售商/平台运营）决定菜单可见性和页面布局；权限角色（管理员/操作员/只读）决定功能按钮和数据操作权限。关键设计是——后端 API 层按业务角色做数据过滤，前端按业务角色动态加载路由，菜单和数据范围都从 token/claim 来，不本地维护。
>
> 举个例子：同一个'订单列表'页面，采购经理只能看自己公司的订单，平台运营能看到全平台。同一个公司内，财务看得到金额但不能下单，采购能下单但看不到财务数据——数据权限和菜单权限是分层的。"

### 被问"你们合同签约(电子签章)怎么做的？和线下签约比有什么优势？"

> "B2B 大宗的合同跟 C 端电商订单是两码事——金额动辄千万，条款十几页，涉及质量标准/计量方式/违约罚则/异议处理/管辖权，每一条都有法律后果。
>
> 我们做了四点：第一，**智能合同模板**——80% 的标准条款从订单自动带入，业务员只需核对品种/数量/价格，降低人工出错；第二，**在线协同编辑**——改一版推送一版，双方修改历史完整保留，不用微信来回传 Word；第三，**多级审批流**——法务→风控→业务总监自动流转，超金额加签 CEO，杜绝'一个人拍板'的风险；第四，**电子签章**——对接 e 签宝/法大大，签章后合同不可篡改、自动存证归档到 ES，支持'去年跟 XX 钢厂签的所有含质量异议条款的合同'这种全文搜索。
>
> 效果：签约从纸质合同快递来回 3 天变成线上 20 分钟，合同纠纷从'找不到原版'变成'一秒溯源到签章时刻'。"

### 被问"支付环节怎么设计的？怎么保证资金安全？"

> "B2B 大宗的支付链路跟 C 端完全不同——不是微信支付宝一键付，而是保证金+预付款+进度款+尾款的分阶段支付，还涉及对公转账/银行承兑汇票/国内信用证多种结算方式。
>
> 安全层面我们做了四道防线：
> 第一，**支付计划引擎**——签约后系统自动生成支付计划（保证金 X 日付→进度款 Y 日付→尾款 Z 日付），逾期自动催办，杜绝'忘了付/付晚了'；
> 第二，**银企直连**——对接银行核心系统，大额支付在线完成，不走平台账户、不形成资金池，符合央行 217 号文；
> 第三，**保证金硬控制**——买方保证金不足时系统拒绝进入合同签署和发货流程，不是人为可以绕过去的，杜绝了'先发货再催款'的人情漏洞；
> 第四，**日终自动对账**——系统流水 vs 银行流水每日自动匹配，差异秒级标红，三年零资金差错。"

### 被问"这么多角色，怎么保证数据一致性？"

> "核心抓手是 DS 数据中心（Java 桥接层）。所有交易数据——C 引擎的成交结果、WMS 的库存变更、银行的支付回调——都经过 DS 做协议转换和事件标准化。下游各角色的视图从统一数据源消费，通过 Canal binlog → 缓存服务 → Redis 分发到不同角色前端，保证所有角色看到的是同一份权威数据。"
