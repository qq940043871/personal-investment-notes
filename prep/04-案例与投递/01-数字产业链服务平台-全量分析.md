## 三、整体业务架构（核心第4页）

### 架构设计理念：「四个统一」

| 统一维度 | 含义 |
|----------|------|
| **统一账户体系** | 一个身份贯穿注册→交易→交收→结算全链路 |
| **统一身份认证** | 实名认证 + 企业查 + 卡证识别 + 视频验 |
| **统一订单管理** | 所有交易模式的订单统一入口、统一状态机 |
| **统一资金结算** | 保证金/货款/金融服务资金池打通 |

### 业务流水线（左→右）

```
┌─────────┐    ┌──────────────┐    ┌──────────┐    ┌──────────┐
│ 注册/登录 │ → │    交易      │ → │ 交收申请  │ → │   交收    │
│          │    │              │    │          │    │          │
│·实名认证  │    │ ·挂牌交易(6) │    │ ·合同签署  │    │ ·多种交收 │
│·PC/手机  │    │ ·拼单集采    │    │ ·履约金支付│    │ ·对接仓储 │
│·微信/支付宝│   │ ·代采交易    │    │ ·货权交割  │    │ ·对接物流 │
│          │    │ ·竞价交易    │    │ ·发票管理  │    │ ·对接签章 │
│          │    │ ·基差点价    │    │          │    │ ·多支付方式│
└─────────┘    └──────────────┘    └──────────┘    └──────────┘
```

**关键洞察**：这是一个**端到端的 B2B 大宗商品交易闭环**——从获客注册到资金清算，不依赖外部系统即可完成完整交易周期。

## 五、交易业务深度分析（第35–80页，最大章节）

### 5.1 七大交易模式矩阵

| 模式 | 页码范围 | 业务场景 | 技术复杂度 |
|------|----------|----------|-----------|
| **挂牌交易** | s41–44 | 卖方挂单/买方摘单，最基础模式 | ★★☆ |
| **竞价交易** | s43–46 | 公开竞价/拍卖，含价格阶梯 | ★★★ |
| **点价交易** | s54–56 | 基于期货/指数的远期定价 | ★★★★ |
| **产融套保** | s56–58 | 交易+期货对冲锁定价格风险 | ★★★★★ |
| **代采业务** | s58–60 | 平台代为采购，融资属性强 | ★★★★ |
| **谈判交易** | s61–63 | 一对一协商定价后走系统流程 | ★★★ |
| **协议交易** | s77–79 | 长协框架下的批量执行 | ★★★☆ |
| **拼单集采** | (嵌入挂牌) | 多买方联合采购降本 | ★★★ |

### 5.2 交易模式技术要点

- **挂牌交易** 支持 6 种子类型：保证金挂牌、合同挂牌、竞价挂牌、预约挂牌、协议挂牌、谈判挂牌
- **点价交易** 是该平台的差异化竞争力——允许买卖双方先定数量/品质，再择时参考期货/指数确定最终价格
- **产融套保** 将交易与期货对冲绑定，实现"现货交易+期货保值"一体化
- **代采业务** 引入平台信用背书，解决中小企业资金痛点

| **订单秘书** | 自动签约；多维度分析（价格/时间/供应商/交货地）；变更跟踪 | 减少人工操作 |
| **合同卫士** | 合同审批/版本比对/履约跟踪/电子存证/物流核查/成本核算/风险判断 | 法律合规保障 |
| **待办管家** | 待办自动分类（自动办理/手动确认）；风险预警；业务待审 | 不遗漏关键节点 |
| **融聚通伴** | 客户间互联互通；知识库/CRM；资讯信息库；售后客服 | 提升客户粘性 |
