0核心结论：四个客户恰好落在交易模式的四个不同象限

只讲"我们服务过四类客户"，面试官听到的是四个 logo；讲"四个客户恰好覆盖了交易模式的四种形态"，听到的是一套产品能力被四种商业逻辑验证过。

这是本页存在的唯一理由：产品四层架构不是设计出来的，是被四种交易模式逼出来的。

1逐客户拆解：按框架十层对照

河南能源大宗商品交易平台 + 中原云商我方承建两套系统象限：产业方主导 · 零货权风险
交易模式销售端竞价 / 挂牌 / 长协 / 邀约专场四种；采购端电子招投标 + 阳光采购。不持有库存、不买断、不赌行情——平台的价值是"发现价格 + 合规免责"，不是赚价差。披露
谁承担风险销售端几乎零风险（背靠集团库存）；采购端的风险是合规与审计风险，不是货损风险。所以它最怕的不是亏钱，是留痕缺失被审计追责。推断
履约与物流典型重资产 / 半重资产：依托集团自有铁路专用线、港口堆场、仓库。煤化工品类对质检与磅差极度敏感（甲醇、1,4-丁二醇的杂质与水分争议直接改盈亏）。平台做的是物流管理 + 仓单管理，不是调度优化。推断
资金与金融当前以结算 + 电子签约为主；供应链金融是转型方向（2026 年官方招标公告可查）。所以它的风控优先级是：先合规留痕，再资金安全，最后才是金融。披露
盈利模式平台侧不应赚自营价差——那 8 亿溢价是集团收入，不是平台收入（最容易讲错的一点）；合理结构是交易服务费 + SaaS/系统费 + 金融分润（转型后）。推断（务必讲清）
会计口径应为净额法（不控制货权、控制权未实质转移，只收服务费）→ 营收规模小、毛利率高。若误按总额法并表，规模会虚增百倍且引审计问询。推断
组织机制品类经理制的典型样本：煤/甲醇/乙二醇各自有懂行的品类经理负责授标、定价、磅差争议；系统管确定性流程，人管例外。推断
核心指标客户侧看溢价增收额（累计 8 亿，2024 当年破 1 亿）+ 采购周期（20 天→7 天）；平台侧应看交易吨数、活跃供方数、采购合规率、招投标争议率。推断
避开的死法避开"只做信息黄页"——它有竞价、长协、招投标三套真实交易规则；也避开"撮合与自营边界模糊"——它根本不碰自营，边界天生干净。
最可能的坑规模不经济：只服务集团内部，成交量天然封顶，平台永远长不大。2026 年转型"电商+物流+供应链金融"正是为了破这个天花板——说明它自己也清楚这个风险。推断
陕西煤炭交易中心（西煤交易）持央行双支付牌照象限：纯撮合 + 持牌资金通道
交易模式竞价、挂牌、报价、招标采购、定量交易多种；但真正的差异点不在交易形式，而在"1+N"——用支付把交易、物流、金融、数据串成一条链。披露
履约与物流轻资产第四方物流：不自建车队，整合 203 家承运商、19.98 万笔运单，做电子围栏 + 在途可视化。物流在这里的真实作用不是省运费，是生成"货真"证据链——有了它金融才敢放款。运力 587 万吨为电厂降本 1800 万。披露
资金与金融四家里唯一能合规"过手资金"的一类：西煤支付做统一收款 + 智能分账，规避平台"二清"风险；金融层做应收账款融资、票付通（一手交货一手交票）。披露→ 这正是框架里"平台尽量做助贷而非放贷主体"的持牌版本：资金是银行的，风险是平台的，牌照是自己的。推断
盈利模式五级火箭：交易服务费（引流）→ 支付手续费（现金流抓手）→ 物流服务费（粘性）→ 金融分润（利润）→ 数据与指数（定价权）。这是六层盈利清单里唯一集齐 5 项的。披露
会计口径净额法：营收是服务费与手续费，不并表货值。煤炭 6.01 亿吨 / 2846 亿元是客户成交规模，绝不能当成平台营收。推断
组织机制国有平台公司形态，风控、法务、结算中台化天然成立；获客靠行政力量（省属国企强制/引导上线、签框架协议）——地推成本极低，但增长受行政边界限制。披露
核心指标支付金额（累计 2350 亿）、交易吨数、承运商数量与活跃度、煤炭价格指数影响力、融资笔数（大唐电厂 39 笔 2 亿）。
避开的死法避开"只做信息黄页"——靠支付 + 物流 + 数据把"认识之后还要用"的环节全部锁住；也避开"涉融资性贸易"——有真实货物流转 + 有支付牌照 + 有物流证据链，是合规融资的完整形态。推断
最可能的坑行政依赖：省属国企强制上线带来存量，但增量必须靠外部客户与金融/数据服务。转型公告就是它对天花板的回应。推断
清镇"富矿精开·清铝集采"平台政府平台公司运营象限：政府准调控 + 代采垫资
交易模式不是纯商业撮合，是行政化统配统销：原矿/粗矿"高效统配统销、分级分类使用"，矿产资源优先向重点企业倾斜——平台是产业政策工具。同时叠加集采 + 代采（真商业动作）。披露
履约与物流整合采矿/配矿/用矿/物流/信息/刷卡六大系统；140 台物流车 GPS 全覆盖，21 家核心用矿企业月度 355 万吨用矿量实时统计。铝土矿物流成本占比极高 + 品质争议多 → 必须重仓物流与检验，平台绑定运力。披露
资金与金融四家里最大的一笔风险敞口：2025 年代采 4.03 亿元，典型案例柯印数码代采 1.2 亿铝卷省 50 万。代采本质是平台垫资 / 受托支付，对应框架里"代理采购垫付"——风控核心是货权管控：货在监管仓、仓单电子化，才能把钱借出去。银行基于平台交易数据放贷（工行、贵阳银行线上结算接入）。披露
盈利模式代采服务费 + 金融分润 + 集采通道服务费。但真正的买单动机是财政与产业政绩——税收流失堵住、资源流向可管、龙头企业能贷到款。推断
会计口径集采/代采若涉及控制权转移，可能落到总额法（营收大、毛利极薄）；平台服务部分是净额法。混用是最高审计风险点。推断（重点风险）
组织机制政府平台公司，KPI 不是成交额而是可管、可查、可贷；风控与监管优先级高于交易体验。数据上报（资源税刷卡实时上传）是刚性要求。披露
核心指标代采金额与节约额、监管用矿量（628 万吨/年）、企业获贷笔数与额度、资源税入库额、平台接入车辆数。客户侧核心 KPI 是税收与产业，不成交量。
避开的死法必须避开"涉融资性贸易 / 重复质押"——这是政府平台最大的雷。做法是货在监管仓、仓单电子化、税卡直连三条线同时成立。推断
最可能的坑规模不经济 + 垫资压顶：代采规模取决于财政与银行授信，不是市场需求；一旦上游铝价下行或用矿企业资金链断裂，平台自己承担坏账。所以它的扩量必须等金融配套跟上。推断
广西晔龙国际贸易郑商所产融基地 · 进口菜粕全国第一象限：套保型自营
交易模式完全自营：一手货源买断，报价"期货价 + 基差"，下游点价成交。不做撮合、不收服务费，赚进销价差。披露
履约与物流轻资产：自有防城港鼎龙物流 + 广西/广东/福建/江苏港口采购团队，港口集散地"贸易+物流"一体。粕类季节性强、损耗、非标 → 产地端整合与分级标准是胜负手。披露 + 推断
资金与金融不碰金融，但做了比金融更狠的两件事：①套保——2012 年菜粕期货上市起做套期保值、期现套利、跨期套利、豆菜粕跨品种套利；②预售——先锁下游需求再组织货源，以销定采。结果：贸易量从 3-5 万吨干到 50 万吨。披露
盈利模式纯自营价差。这是六层盈利清单里最危险的一项：规模最大、毛利最薄、且吃行情。它之所以能活，是因为用套保把价格风险转移成了基差风险。推断
会计口径总额法的教科书样本：自营买断、货权完整转移 → 营收巨大、毛利率极薄。50 万吨 × 价格是营收，不是利润。面试时若把贸易额说成营收，就是完全不懂会计。推断（高危）
组织机制品类经营 + 采购/销售对锁 + 期货操作三类岗协同；3000 家下游客户与上游央企/外企直连；已办产融赋能会议（300+ 决策者），"它已经是半个平台"。披露
核心指标贸易量、套保比率（套保敞口 / 总敞口）、基差敞口、点价转化率、下游客户数与复购率、价差与库存周转。
避开的死法避开"行情赌注"——2012 年之前就是一口价裸奔，价格一波动就死；套保 + 基差交易是它的商业模式级进化，不是风控补丁。
最可能的坑套保了但基差没管住：套保能锁价格，锁不住"期货涨了但货没到"的基差风险；敞口实时计算是刚需——这正是期货套保风控子系统存在的理由。另一死法是"规模不经济"：每吨毛利过薄时，货量涨了反而亏更多。推断

3框架照出来的五条新洞察（可复用到下一个客户）

洞察 1｜客户收益 ≠ 平台收入：这是最容易讲错、也最致命的一处

河南能源"溢价增收累计 8 亿"是集团收入（国企里溢价几乎直接等于净利润），不是平台收入；西煤"支付 2350 亿"是客户成交与资金规模，平台赚的是手续费；晔龙"50 万吨贸易量"是营收，总额法下毛利率可能不到 1%。

正确说法："我建设的平台为客户创造了这些数据与收益，平台自身通过交易服务费、供应链服务费、金融分润与数据服务实现商业化。"——这句话说出口，专业度立刻拉开差距。必背

洞察 2｜会计口径是运营模式的照妖镜：规模可差百倍，真实盈利能力可能接近

晔龙（自营买断）走总额法，营收几十亿、毛利极薄；西煤/河南能源（服务）走净额法，营收小、毛利好看。但两者真实盈利能力可能接近——因为自营赚薄利差，撮合赚高费率。

所以谈"服务过多大规模"时必须主动区分交易规模与平台营收，否则会被懂财务的面试官当场问穿。国联股份曾因"同一客户不同订单分别用总额法/净额法"被监管问询，是现成的行业案例，可在追问时引用。行业公开案例

洞察 3｜风控能力必须跑在金融业务前面——清镇的 4.03 亿就是活证据

框架第三条铁律"控货能力必须跑在金融业务前面"在清镇被验证：敢代采 4.03 亿，前提是货在监管仓、仓单电子化、资源税刷卡直连、银行在线结算接入——三条线同时成立才敢垫资。

反过来说：我们产品里的仓单与风控中心不是"合规功能"，它是金融业务的前置条件。讲架构时把仓单/风控讲在金融之前，逻辑才自洽。

洞察 4｜四种客户 = 四种"KPI 语言"，同一句功能描述要换四种说法

同一套仓单系统：国企说"盘亏要能追责"，政府说"货权要能核验"，贸易商说"套保敞口要能算清"，资金方说"质押率要能自动盯"。

能力完全相同，优先级与验收标准完全不同。这就是为什么同一底座必须分端设计：管理端给政府/平台方，客户端给企业，风控中心给资金方。架构原则的直接来源

洞察 5｜所有客户的终点都是"卖服务"，不是"卖交易"——交易本身越来越薄

西煤的 1+N（支付/物流/金融/数据）、河南能源的"电商+物流+供应链金融"转型公告、清镇的"平台开放化 + 金融多元化"、晔龙从贸易商走向产融基地——四条路径都是从"做交易"走向"做基础设施"。

对应到产品演进：交易层（门户撮合）→ 管理层（运营风控）→ 服务层（物流/金融/云仓）→ 数据层（指数/订阅/SaaS）。我们的四层架构，就是这条路线的预演。

4收尾：四种模式如何反推我们的产品四层架构

产品层被哪种客户逼出来对应能力（讲到什么程度算够）
门户与交易层河南能源（多模式规则）、西煤（撮合入口）竞价/挂牌/长协/招投标多模式并存、交易规则可配置、行情与挂牌联动、倒计时与出价队列的并发公平性
管理与运营层清镇（监管视角）、河南能源（合规留痕）审批流、操作日志与版本链全链路留痕、多层级监管报表、上帝视角、机构协同与主数据 MDM
物流·金融·云仓层西煤（轻资产物流）、清镇（代采垫资）、晔龙（港口物流）智慧物流（调度/轨迹/电子围栏）、电子仓单与货权核验、代采与受托支付、应收/存货融资、期现套保风控
数据与风控层四家共同刚需敞口实时计算、风险限额分级预警、风控中心、价格指数与数据服务（西煤已验证的数据变现路径）
收尾话术（可直接背）："这四个客户的货权风险跨度很大——从完全不承担，到代采垫资，到全额自营。但越承担风险，越依赖同一套基础设施：仓单、履约、敞口与风控。所以我们的产品看起来模块很多，本质是把'风险从不可见到可见'这件事做到了四个客户都能接受的程度。这也解释了为什么架构从撮合一直做到仓单和风控——不是功能堆得多，是客户的货权风险链条就这么长。"

5口径提醒（讲之前必须记住三条）

① 客户收益 ≠ 平台收入

溢价增收、支付金额、贸易吨数、代采金额，全部是客户侧的经营成果。平台自身收入靠服务费、金融分润、数据订阅。混着讲是最大扣分点。

② 披露事实与框架推断要分开

标〔披露〕的可以当事实讲；标〔推断〕的必须说"我的理解是"、"按行业惯例推测"。面试官追问时，能区分"客户公开的"和"我判断的"，反而加分。

③ 我方承建范围只在河南能源

大宗平台 + 中原云商两套系统为我方承建（对外未署名），可讲"我们做的"；其余三家只能讲"我们平台的设计来自这类客户的共性需求"。技术细节只讲自己实际负责的部分。
