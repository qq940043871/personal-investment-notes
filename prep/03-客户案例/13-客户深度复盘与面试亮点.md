# 一、陕西煤炭交易中心（西煤交易）

## 1.1 客户画像
- 陕西省物流集团旗下（2019 年划转），持有**央行互联网支付 + 跨境人民币支付双牌照**——这是它最硬的护城河
- 全国煤炭现货交易、交割量最大的线上交易综合服务商，西北第一
- 参与起草全国首部《煤炭现货交易规则》团体标准（2025）
- "1+N"服务体系：西煤交易（交易）+ 西煤支付（支付）+ 西煤物流 + 供应链金融 + 大数据

## 1.2 运营模式拆解（⭐面试讲这个）
它的商业模式不是"收交易佣金"这么简单，而是**交易为入口、支付为抓手、物流金融数据变现**的五级火箭：

1. **交易层（入口）**：竞价、挂牌、报价、招标采购、定量交易多种模式。核心打法是**把省属国企的煤炭销售强制/引导上线**——陕煤集团、延长石油、陕投集团、陕西有色金属集团、中陕核签订平台服务框架协议，2025 年省属企业成交量 2.45 亿吨、销售增收 15 亿元。**逻辑：阳光交易是政治任务，平台是合规基础设施。**
2. **支付层（现金流抓手）**："西煤支付"= 统一收款+智能分账，帮电商平台规避"二清"风险；2025 年第三方货款支付 155 亿元，累计 2350 亿元。**逻辑：交易可以不赚大钱，资金过手就有一切。**
3. **物流层（降本粘性）**：运力交易 587 万吨为电厂降本 1800 万；整合 203 家承运商、19.98 万笔运单、在途轨迹可视化（电子围栏/图像监控）。**逻辑：物流数据是货物真实性的证据链，反哺金融。**
4. **金融层（变现）**：基于真实贸易背景做应收账款融资、在线票据贴现（票付通：一手交货一手交票）；为大唐电厂煤炭采购融资 39 笔共 2 亿元。**逻辑：有支付+物流+交易三重数据，银行才敢放款。**
5. **数据层（定价权）**：陕西煤炭价格指数（全国第三个区域性煤炭指数）+"产销储运价"全链条数据服务。**逻辑：指数即话语权。**

## 1.3 核心痛点 → 我们的价值
| 它的痛点 | 我们平台对应的方案 |
|---------|------------------|
| 省属国企交易整合，流程必须标准化、可审计 | 管理端合同/交易/审批全流程线上化 + 操作留痕 |
| 大额货款结算安全与效率（二清风险） | 支付渠道适配器 + 资金预检 2PC + 银行适配器设计 |
| 电厂运力组织与在途监管 | 智慧物流子系统：运力交易/调度/在途监控/电子围栏 |
| 中小贸易商融资难 | 供应链金融：基于真实合同履约数据的应收/存货融资 |
| 多层级监管报表需求 | 上帝视角 + 决策驾驶仓 |

## 1.4 90 秒面试话术
"我以陕西煤炭交易中心为例讲平台价值。它是全国最大的煤炭现货线上交易平台，2025 年交易量 6 亿吨、金额 2846 亿元，服务 1.2 万家客户。它的运营逻辑是'交易做入口、支付做抓手、物流金融变现'——它有央行支付牌照，累计支付货款 2350 亿；物流端管着 200 多家承运商、近 20 万笔运单。这正验证了我们平台架构的判断：**大宗产业电商的核心壁垒不在撮合，而在履约和资金**——交易只是入口，支付、物流、金融才是变现层。我们平台的四层架构（门户交易→管理运营→物流金融云仓→风控）就是按这个商业逻辑设计的。"

## 1.5 追问预案
- **问：它有支付牌照，你们的平台怎么办？** 答："正是关键设计点。我们采用支付渠道适配器架构，对接银行存管/第三方持牌机构，平台自己不碰资金池——这也是监管合规的必然选择。"
- **问：国企强制上线交易，系统最大的挑战是什么？** 答："审计与留痕。每一笔交易从挂牌到成交到结算全链路可追溯，所以我们把操作日志、审批流、版本链做成了一级能力，而不是事后补的。"

## 2.2 运营模式拆解（⭐⭐必须讲透）
两条腿走路：**对内是溢价销售工具，对外是阳光采购基础设施**，正在向第三阶段进化：

2. **采购端（合规）**：中原云商阳光采购平台，河南省国资委指定的阳光采购试点，累计成交项目破万（10560 项）。采购周期从平均 20 天降到 7 天，电子签约 5 分钟完成并存档。**逻辑：国企采购的核心诉求是"合规免责"，平台就是免责证据链。**
3. **数据端（决策）**：河南能源大数据中心，1000 万+条数据（宏观经济/行业运行/下游客户/港口流通/运力），打通"信息孤岛"，支撑产销衔接。
4. **进化方向（2026 正在干）**：官方公告正在采购"转型升级为煤炭化工产业互联网综合服务平台"项目——目标模式就是**"电子商务 + 现代物流 + 供应链金融"**。**这句话面试必用：客户的下一步战略和我们产品的四层架构完全同构，说明我们对行业演进的判断是提前半步的。**

# 三、贵州清镇"富矿精开·清铝集采"平台

## 3.1 客户画像
- 清镇市政府主导（清镇工投优联/经发集团建设运营），2024 年 7 月上线
- 背景：清镇铝土矿保有储量 3.9 亿吨，**占全省 34%、贵阳市 88%，全省第一**——但"富而不活"，资源综合配置不强、产能释放不足
- 数字化管理 + 电子交易两大板块，整合采矿/配矿/用矿/物流/信息/刷卡六大系统

## 3.2 运营模式拆解（⭐政府平台的玩法和前两家完全不同）
1. **资源统配统销（核心逻辑）**：不是自由市场，而是把原矿/粗矿"高效统配统销、分级分类使用"，**矿产资源优先向重点企业倾斜**——政府用平台实现产业政策，不是纯商业撮合
2. **全链监管（政绩逻辑）**：矿山产能、配矿加工、用矿需求、物流车辆轨迹实时跳动；21 家核心用矿企业月度 355 万吨用矿量实时统计、140 台物流车 GPS 全覆盖、资源税刷卡数据实时上传——**平台同时是税务监管工具，堵税收流失**
3. **代采金融（变现逻辑）**：集采+代采模式，2025 年协同金融机构完成 4.03 亿元代采服务，为企业节约成本约 80 万元；典型客户柯印数码通过平台代采 1.2 亿元铝卷省 50 万，且**银行基于平台交易数据给企业放贷**——交易数据即信用
4. **规模数据**：64 家企业入驻、交易量超 100 万吨、累计成交额近 20 亿元、14 个品种（从铝土矿扩展到氧化铝/铝板等）、平台监管年用矿量 628 万吨；工行、贵阳银行线上结算接入

## 3.3 核心痛点 → 我们的价值
| 痛点 | 方案 |
|------|------|
| 产能/配矿/用矿/物流数据分散在六套系统 | 机构协同（多主体数据打通）+ 主数据 MDM + 物联网接入（iot） |
| 税收流失、资源流向失控 | 资源税刷卡数据直连 + 全链监管（上帝视角/风控中心的设计直接复用） |
| 中小加工厂垫资难 | 代采模式 = 供应链金融的"核心企业代采"场景（我们的 finance 模块 buyer/core-enterprise 双视角） |
| 物流车辆监管 | 智慧物流 GPS 轨迹 + 电子围栏 |
| 政府要报表、企业要效率（两套视角） | 我们产品天然分端设计：管理端给政府/平台方，客户端给企业 |

## 3.4 90 秒面试话术
"贵州清镇的'富矿精开·清铝集采'代表第三种模式：**政府主导的区域资源平台**。清镇有全国最大的整体连片铝土矿矿区，3.9 亿吨储量占全省三分之一，但以前'富而不活'——资源税流失、配矿靠关系、小加工厂垫资难。平台 2024 年上线后做了三件事：一是把矿山、配矿、用矿、物流、刷卡六个系统的数据打通，140 台物流车 GPS 全覆盖，资源税数据实时上传；二是搞统配统销加代采金融，一年代采 4 亿多元，企业凭平台交易数据就能拿到银行贷款；三是交易额做到近 20 亿。这个案例给我们的启发是：**政府类客户的 KPI 不是撮合量，是资源可管、税收可查、企业可贷**——所以我们产品的机构协同端和风控中心，天然就是为这类'监管+交易'双视角客户准备的。"

## 3.5 追问预案
- **问：政府平台和企业平台设计上最大的区别？** 答："委托方不同导致优先级倒挂。企业平台先做交易体验，政府平台先做监管可视——所以我们把'同一数据底座、多端视角分离'作为架构原则，管理端、客户端、监管驾驶仓各取所需。"
- **问：代采模式的资金风险？** 答："代采本质是平台垫资/受托支付，核心风控是货物管控——货在监管仓、货权凭证电子化，才能把钱借出去。这正是我们仓单系统设计的出发点。"

# 四、广西晔龙国际贸易（粕类贸易商）

## 4.1 客户画像
- 2009/2011 年起家，南宁总部，防城港设鼎龙物流等配套物流公司，拥有自主进出口权
- **全国最大的进口菜籽粕贸易商，市场份额 >15%**；年贸易量 50 万吨（2018-2022 年菜粕年销 50 万吨+）；服务约 3000 家下游饲料企业
- 经营豆粕、菜粕、葵花粕、椰子粕、棕榈粕、鱼粉、木薯等进口饲料原料，上游对接央企/外企/大型集团
- **郑商所"产融基地"**——行业期现结合的标杆企业

## 4.2 运营模式拆解（⭐⭐这是期货套保子系统的最佳客户故事）
1. **采购端：一手货源 + 衍生品锁价**。坚持第一手采购，从 2012 年菜粕期货上市起就用套期保值、期现套利、跨期套利、豆菜粕跨品种套利管理价格风险
2. **模式进化（⭐⭐最佳故事线）**：从传统"一口价"贸易**转向基差交易**——报价变成"期货价 + 基差"，下游点价成交。效果：经营风险大幅下降 + 提前锁定远期销售 + 销售与采购同步；菜粕年贸易量从早期 3-5 万吨增长到 50 万吨。**这个转型就是'期现共生'：不做套保的贸易商在波动行情里是裸泳。**
3. **销售端：预售模式**。先锁下游需求再组织货源，替工厂节省采购成本和时间——本质是**以销定采 + 远期合同管理**
4. **物流配套**：防城港自有物流公司 + 广西/广东/福建/江苏港口采购团队——港口集散地的"贸易+物流"一体
5. **生态输出**：作为产融基地办产融赋能会议（300+ 决策者参会）、养研发团队向 3000 家下游客户输出期现理念——**它已经是半个平台**

## 4.3 核心痛点 → 我们的价值
| 痛点 | 方案 |
|------|------|
| 基差交易合同结构复杂（点价期/基差/升贴水/违约处理），Excel 管不过来 | 合同管理：基差点价定价模式 + 合同版本链 + 违约处理流程 |
| 敞口实时难算：现货头寸和期货头寸两张皮 | **期货套保风控子系统**：套保策略绑定现货合同、敞口实时计算、风险限额与分级预警、期现平衡表 |
| 预售+远期采购的履约节奏管理 | 履约计划批次拆分 + 五种交收模式（分期/定金+尾款正是预售场景） |
| 3000 家下游客户的信用与账期管理 | 客户信用档案 + 资金中心 + 结算对账 |
| 进口货物在途/港口库存可视化 | 云仓 + 物流跟踪 + 质检单据数字化 |

## 4.4 90 秒面试话术（⭐⭐连着你自己的期现联动经验）
"广西晔龙是我最喜欢讲的客户，因为它是**贸易商如何用系统化手段活下来**的教科书。它是全国最大的进口菜粕贸易商，份额超过 15%，年贸易量 50 万吨。2012 年之前它做'一口价'贸易，价格一波动就裸奔；从菜粕期货上市开始转向套期保值，后来干脆把整个商业模式升级成**基差交易**——报价报'期货价+基差'，下游点价成交。就这一个转型，贸易量从 3-5 万吨干到 50 万吨。但基差交易对系统的要求极高：点价期管理、敞口实时计算、期现两头对账——手工 Excel 根本扛不住。这正是我们期货套保风控子系统的设计场景：**套保策略绑定现货合同、敞口实时计算、风险限额分级预警**。我自己也在做期现联动相关的方案设计，比如基于上海石油天然气交易中心和上期所的期现联动交易方案，底层逻辑和晔龙的实践完全同源。"

## 4.5 追问预案
- **问：基差交易系统里最难的点？** 答："点价的权利义务建模。买方在点价期内随时可能点价，系统要实时算'已点价量/未点价量/点价截止'，并联动保证金与违约预警；未点价敞口和期货头寸要做实时净敞口表——这是状态机+事件驱动的典型混合场景，正好用我们的双轨履约引擎。"
- **问：贸易商和平台客户的系统诉求最大区别？** 答："平台客户要'多边公平'（监管、留痕、撮合），贸易商要'单边盈利'（敞口、套保、资金效率）。所以我们的企业客户端把贸易商做成独立角色，配期现风控；平台端则强调风控中心。一套底座、两种价值观。"

# 五、中国-东盟林业资源全要素交易平台（广西林控）（⭐⭐我方承建的第二个完整平台）

## 5.1 客户画像
- 运营方：**广西林控互联网平台有限公司**——由**广西壮族自治区林业局批准设立的国有全资**林业产业互联网平台公司（2022 年 5 月成立，注册地南宁五象新区），持**增值电信业务经营许可证桂B2-20220646（在线数据处理与交易处理业务，仅限经营类电子商务）**

- 交易品种：**活立木（"包青山"）、林地林木流转**、原木、人造板、木业原料、营林物资、林木种苗、林下经济产品、林果、林茶、花卉苗木、香精香料
- 交易主体以**广西区直国有林场**为主：大桂山、高峰、派阳山、雅长、三门江、七坡林场、南宁树木园、良凤江国家森林公园，另有广西中林国控、广东肇鼎储备林、藤县森茂林投、广西桂平西山茶、广西森工东腾人造板、广西高林肥业、乐业森乐林业投资等

## 5.2 运营模式拆解（⭐⭐这是"要素交易场所"型平台的第三条路）

**它既不是集团自用型（河南能源），也不是纯撮合持牌型（西煤），而是"政府授权设立的要素交易场所"**——把国有林场的林木资产、林地经营权推到公开市场上竞价，用价格发现证明"国有资产没贱卖"：

1. **交易模式（四件套）**：**竞价**（正向竞价=竞价销售 / 反向竞价=竞价采购，双向都有）、**挂牌**（寄货代售，支持批量摘牌）、**产能预售**、**专场**（公开专场/定向专场/客户专场）。标的形态很特殊：活立木"包青山"按**林班/小班整片打包**竞价，单个标的动辄百万级。**逻辑：非标要素要线上化，靠的不是标准化商品，而是标准化的规则与流程。**
2. **价格发现（平台最硬的 ROI）**：2026 年 1 月广西中林国控活立木项目——挂牌 19 个标的、成交 11 个、**成交金额 2385 万元、整体溢价 171 万元、溢价率 7.72%**；其中单个标的挂牌价 170 万元，**历经 32 轮竞价以 201 万元成交，溢价率 18.2%**。**逻辑：一次公开竞价把"林场多收钱 + 国资不流失 + 过程可审计"三件事同时办了，这是国企最愿意买单的价值。**
3. **收费结构（要素交易所的商业模式）**：**挂摘手续费（按成交价比例，如 0.3%）＋ 买方履约保证金（定额/按比例）＋ 挂摘保证金（固定金额/按比例）＋ 交易商会员服务费**。并且用**费率做运营杠杆**——"限时免收挂牌交易模式及林下经济绿色产业专区交易服务费""继续执行正向竞价项目服务费费率优惠"，公告多次续期。**逻辑：费率不只是收入，更是引导交易模式迁移与品类冷启动的抓手（所以必须系统可配，不能硬编码）。**
4. **专区运营（垂直品类冷启动）**：特色专区 = **林下经济绿色产业专区**（子站 lx.zgdmly.com），与"广西区直国有林场林下经济绿色产业联合会"签约合作，单独建"林果/林茶"类目，卖茶叶、八角鲜果、松香、麻竹笋、益智鲜果等，服务费连续公告免收。**逻辑：用一个专区承接一个产业带，比改主站便宜十倍。**
5. **产业链服务（"交易、结算、仓储、物流、金融"五件事全在系统里）**：交易中心之外还有**融资中心**（合同融资/订单融资/预付款/仓单质押/赎回/融资费）、**发票税务**（税收管理/购销信息/退税）、**云仓物流**（货源信息/车源）、**资金中心**（入金）、**多端**（PC 客户端 + 手机 APP + 交易商/仓管员双角色登录）。**逻辑：和企业客户一样，它的终点也是"从做交易走向做基础设施"。**

## 5.3 核心痛点 → 我们的价值（⭐这家技术细节我们最讲得清，因为是自家承建）

## 5.4 90 秒面试话术（⭐⭐综合"要素市场化 + 我方承建"双重亮点）

"**中国—东盟林业资源全要素交易平台也是我们承建的**，运营方广西林控是自治区林业局批准设立的国有全资平台公司。它跟煤炭、化工那些客户最大的不同是：**交易的标的是'资源要素'本身**——活立木包青山、林地林木流转，一个标的动辄一两百万，非标、要看山、要踏勘。所以它的系统重心不是撮合效率，是**规则与证据**：一套交易规则 + 交易商管理办法 + 竞价/挂牌/林权流转三类细则，光历史废止版本就留着 21 条；一笔竞价要设起始价、保留价、加价幅度、180 秒倒计时周期，还要按成交价 0.3% 收挂摘手续费、按标的收定额履约保证金和摘牌保证金。它的价值也能量化：2026 年 1 月广西中林国控的一个活立木项目，19 个标的成交 11 个、成交 2385 万元，整体溢价 171 万元、溢价率 7.72%；其中一个标的从 170 万起拍、**经过 32 轮竞价以 201 万成交，溢价 18.2%**。**这就是要素市场化的价值——林场多收钱、国有资产不贱卖、过程全留痕，审计问得住。** 这个案例对我们的意义是：它证明我们的竞价引擎、保证金与手续费体系、规则版本链、专区类目管理这一整套，既能打煤炭化工这种大宗商品，也能打林权这种非标要素——**底层是同一套'交易 + 履约 + 资金 + 风控'能力。**"

## 5.5 追问预案
- **问：活立木这种非标资产怎么做线上交易？** 答："把不能线上化的部分结构化。踏勘信息、标的清单（林班/小班/面积/蓄积）作为标的附件，可线上化的部分（出价、保证金、成交、交收）严格线上。平台甚至支持挂牌方通过公告'变更标的清单部分内容'，保证线上成交价和线下实物一致——靠清单 + 备注 + 公示来锚定，而不是靠聊天记录。"
- **问：180 秒倒计时周期是什么意思？** 答："延时竞价规则——最后时刻出价会触发延时，防止压哨出价让其他人没有反应机会。技术底线是服务器时间为唯一基准（平台详情页明确写'出价以服务器时间为准'），客户端时间不可信，否则竞价公平性无从谈起。"
- **问：保证金和手续费怎么设计？** 答："分三层。履约保证金约束买方履约（定额或按比例），挂摘保证金约束挂单/摘牌行为（固定或按比例），手续费按成交价比例收（如 0.3%）。出价前做余额预检，成交后做冻结/释放/对账；费率还必须支持'限时免收''专区减免'这类运营策略，所以费率一定是配置项而不是写死的常量。"
- **问：国有林场资产交易最怕什么？** 答："怕'贱卖'和'说不清'。所以一是公开竞价 + 保留价机制保证价格不失控；二是全程留痕 + 结果公示保证过程可审计；三是交易商资质审核 + 风险告知书保证参与主体合规。这三条其实和西煤那种国企合规逻辑是共通的——**国企买单的从来不是功能，是'能把责任说清楚'。**"

# 六、跨客户总结：三条可复用的行业洞察（面试的"高度"所在）

## 洞察 1：产业电商的盈利公式分层
"撮合不赚钱，履约建壁垒，金融才是利润，数据是定价权。"——西煤（支付+物流+金融五级火箭）、河南能源（溢价增收）、清镇（代采金融）、晔龙（期现套保）、林控（挂摘手续费+保证金+会员费的"要素交易所"价目表）五个客户全部验证这一条。

## 洞察 2：国企客户和民营客户的购买动机完全不同
| 客户类型 | 真实购买动机 | 产品设计含义 |
|---------|-------------|-------------|
| 省属国企交易中心（西煤） | 阳光合规 + 资金过手 + 政绩 | 留痕、审计、报表是第一优先级 |
| 集团产业电商（河南能源） | 溢价增收 + 采购免责 | 竞价引擎 + 招投标流程合规 |
| 政府平台公司（清镇） | 资源可管 + 税收可查 + 企业可贷 | 监管驾驶仓 + 代采金融 |
| 国有要素交易场所（林控） | 国有资产不贱卖 + 过程可审计 + 区域产业带带动 | 竞价价格发现 + 规则版本链 + 专区与费率运营 |
| 民营贸易商（晔龙） | 活下来 + 赚价差 | 期现风控 + 履约资金效率 |

# 八、面试组合拳：五个客户的出场顺序建议

1. **先打河南能源**（你的主场，两个平台都是你们承建的，有 8 亿溢价这种硬数字）→ 建立"这人真交付过完整平台"的信任
2. **紧跟林控**（同样是自家承建，且"非标要素也能打"证明产品通用性；32 轮竞价 / 溢价 18.2% 是天然的技术故事）→ 把"完整交付"从一次变成两次，信任翻倍
3. **再打晔龙**（业务深度，基差交易+套保，连你自己的期现联动经验）→ 建立"这人懂衍生品"的专业
4. **然后西煤**（商业高度，五级火箭，支付牌照）→ 建立"这人懂商业模式"的格局
5. **最后清镇**（一嘴带过即可，"政府监管型客户我们也覆盖"）→ 补全版图，不恋战

**总时长控制 4-5 分钟内**，细节留给追问。记住：客户案例是弹药，不是阅兵——面试官问什么打什么，别一上来就把五个名字全报一遍。**如果只来得及讲两个，讲河南能源 + 林控**（都是我方承建，一硬一巧：一个是集团产业电商的标杆，一个是非标要素交易的标杆）。
