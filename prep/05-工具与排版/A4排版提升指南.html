A4 纸张使用与排版提升指南

实用 · 简洁 · 可直接套用 ｜ 适用于报告 / 合同 / 简历 / 邮件 / 表格

一、页面布局与边距最佳实践

A4 = 210 × 297 mm，是国际通用办公纸型。边距直接决定可读性与"正式感"。

文档类型推荐边距（上下 / 左右）说明
正式报告 / 合同25.4 / 31.8 mm（默认）留白多，显庄重、便于装订批注
内部文档 / 材料20 / 18 mm本指南采用值，内容更紧凑
数据密集 / 表格多15 / 15 mm最大化利用版面，但勿低于 12mm
需装订（左侧）左 25–30 mm避免装订遮挡正文
✅ 黄金法则：边距对称 + 不小于 12mm；正文区宽度控制在 150–175mm，每行 30–40 个汉字最舒适（超过 45 字阅读疲劳骤增）。

二、字体选择与层级设置

中文字体推荐

  • 正文 / 报告：微软雅黑、思源黑体（屏幕友好）；宋体（打印正式、合同常用）
  • 标题：微软雅黑加粗 / 等线（清秀现代）；黑体（厚重正式）
  • ❌ 避免正文用艺术字、行楷等装饰字体（不专业、打印易糊）

西文 / 数字字体

  • 正文：Times New Roman（学术 / 合同）、Calibri / Arial（商务清爽）
  • 数字对齐：等宽字体 Consolas / Courier New（表格数字建议）

字号层级（小四基准体系）

层级字号（pt）用途字形
一级标题18–22文档主标题 / 封面粗体
二级标题14–16章节标题粗体
三级标题12–13小节标题粗体
正文10.5（小四）常规内容常规
注释 / 脚注9（五号）说明、页码区常规
✅ 层级铁律：全篇字体不超过 2 种（如「雅黑标题 + 宋体正文」），字号层次 ≤ 4 级。层级靠"字号 + 粗细 + 颜色"区分，不靠花哨。

三、行距与段落间距规范

场景行距段前 / 段后备注
正文（报告）1.5 倍 / 固定值 20–22pt0 / 3–6pt中文正文忌单倍（过密）
标题下方—段前 6–12pt与上文拉开
列表项1.3 倍项间 2–4pt紧凑清晰
表格内文字1.3–1.4 倍单元格内 1.5–2mm避免拥挤
⚠️ 常见错误：整篇单倍行距 + 无段距 = 一坨黑块；段间距过大（>12pt）又显松散。用"固定值行距"比"倍数"更可控，跨软件不变形。

四、页眉页脚配置

页眉

  • 左：公司 / 部门名
  • 中：文档标题（缩写）
  • 右：密级（机密 / 内部）
  • 加一条 0.5–1pt 分隔线

页脚

  • 居中或右侧：第 X / Y 页
  • 左：版本号 / 日期
  • 合同类：加"共 __ 页"防抽页
✅ Word 设置：插入 → 页眉页脚 → 勾选"首页不同"（封面不显示）；页码用"第 X 页 / 共 Y 页"域，自动更新。

五、打印质量优化

  • 导出 PDF 再打：锁定排版与字体，避免对方软件跑版（最重要一条）。
  • 嵌入字体：Word「选项 → 保存 → 嵌入字体」，换电脑不丢字形。
  • 分辨率：图片 ≥ 300 dpi；截图用 PNG，勿直接贴低清图拉大。
  • 灰度打印省墨：彩色图表转灰度前确认对比度仍清晰（红绿在灰度下易混淆）。
  • 打印前预览：检查孤行（段落末行落单在页首）、孤字（标题独占页尾）、表格跨页断行。
  • 双面打印：长文档选"翻转在长边"，装订更顺手。
⚠️ 不要用网页直接 Ctrl+P 打正式文档——浏览器默认边距/分页不可控，先用 Word / 排版工具定型。

六、常见文档类型 A4 排版要点

📄 工作报告 / 方案

  • 封面页：标题 + 副标题 + 部门 + 日期 + 版本，居中留白
  • 目录（≥5 页时加），自动生成可跳转
  • 结构：TL;DR 摘要 → 正文分层 → 行动清单 → 附录
  • 图表配标题与编号（图1 / 表1），正文引用

📑 合同 / 协议

  • 宋体正文（正式）、小四，1.5 倍行距
  • 条款编号：一、1. (1) ① 四级体系
  • 页脚"第 X 页 / 共 Y 页" + 落款处留签名 / 盖章空白
  • 关键金额、日期加粗；避免跨页断条款

📋 简历（CV）

  • 一页 A4 优先（资深 ≤ 2 页）；边距 15mm 省空间
  • 姓名 16–18pt 粗体置顶，联系方式紧随
  • 模块顺序：个人总结 → 经历（倒序、STAR 量化） → 技能 → 教育
  • 用项目符号替代长段落；关键词加粗便于扫描

✉️ 邮件 / 内部通知

  • 主题行含"动作 + 对象 + 期限"（如【请审阅】Q3架构方案 周五前）
  • 正文 3 段内：背景 → 诉求 → 下一步；关键句加粗
  • 附件命名规范：日期_部门_主题_v版本

📊 表格 / 数据清单

  • 首行冻结 + 浅色表头；斑马纹提升可读性
  • 数字右对齐、文本左对齐；千分位 / 单位统一
  • 表格超宽时横向分页或拆为子表，勿缩小到看不清

七、30 秒速查清单

检查项达标值
纸张 / 边距A4，边距 ≥ 12mm，左右对称
字体≤ 2 种，正文 10.5pt（小四）
行距正文 1.5 倍 或 固定 20–22pt
层级标题 ≤ 4 级，靠字号 / 粗细区分
页眉页脚有页码 + 文档标识 +（合同）总页数
打印前导出 PDF、预览断行、嵌字体
配色主色 ≤ 1 个（蓝 / 灰），忌彩虹
✅ 终极心法：排版的目标是"让内容被轻松读懂"，不是"让文档好看"。留白、对齐、一致，三者做到，专业感自然来。
